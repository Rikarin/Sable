# S3018: `break` or `continue` outside a loop

`break` and `continue` act on the innermost enclosing loop, and there is none
here.

## Example

```sable
module Example

fn clamp(_ n: Int) -> Int {
    if n > 10 {
        break
    }
    return n
}
```

## Fix

Use `return` to leave the function early.

```sable
module Example

fn clamp(_ n: Int) -> Int {
    if n > 10 {
        return 10
    }
    return n
}
```
