# S3027: a member does not match a protocol requirement

A type declares a member with the name a protocol requires, but its signature
differs: other parameter or return types, different effects such as `throws`
or `async`, or a static member where an instance one is required (or the
reverse).

## Example

```sable
module Example

protocol Named { fn name() -> String }

struct City: Named {
    fn name() -> Int { return 0 }
}
```

## Fix

```sable
module Example

protocol Named { fn name() -> String }

struct City: Named {
    fn name() -> String { return "city" }
}
```
