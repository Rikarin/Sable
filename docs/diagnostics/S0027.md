# S0027: an `#if` that is never closed

Every `#if` needs an `#endif`, and the end of the file came while one or
more were still open. The message says how many.

## Example

```sable
module Example

#if DEBUG
fn mode() -> String {
    return "debug"
}
```

## Fix

```sable
module Example

#if DEBUG
fn mode() -> String {
    return "debug"
}
#endif
```
