# S0016: a hexadecimal float without a binary exponent

A floating-point literal written in hexadecimal, such as `0x1.8`, must end
with a binary exponent: `p` and a decimal power of two, as in `0x1.8p0`
(1.5) or `0x1p-3` (0.125). Without one, `.8` could not be told apart from
a member access.

## Example

```sable
module Example

fn half() -> F64 {
    return 0x1.8
}
```

## Fix

```sable
module Example

fn half() -> F64 {
    return 0x1.8p0
}
```
