# S0011: a number prefix with no digits after it

A prefix such as `0x`, `0o` or `0b` says which base the number is written in,
and must be followed by at least one digit of that base.

## Example

```sable
module Example

fn mask() -> Int {
    return 0x
}
```

## Fix

```sable
module Example

fn mask() -> Int {
    return 0xFF
}
```
