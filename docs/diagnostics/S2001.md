# S2001: no type by that name

A type was named that nothing in scope declares: not a type in the module,
a generic parameter, or a type that an `import` brought in. The same code
is used for a nested or associated type that the outer type does not have.

Check the spelling and capitalisation, and that the module declaring it is
imported.

## Example

```sable
module Example

fn describe(_ value: Integer) -> String {
    return "\(value)"
}
```

## Fix

```sable
module Example

fn describe(_ value: Int) -> String {
    return "\(value)"
}
```
