# S3399: `@allow` or `@warn` names no lint

A warning from the lint runner itself. `@allow(name)` and `@warn(name)` set a
lint's level for the declaration they are on and everything inside it, and
the name is not one of a lint: a misspelt name would otherwise silently leave
the lint as it was. `sable lint --list` lists the lints.

## Example

```sable
module Example

@allow(unused_locals)
fn scratch(_ seed: Int) -> Int {
    return seed * 2
}
```

## Fix

```sable
module Example

@allow(unused_local)
fn scratch(_ seed: Int) -> Int {
    return seed * 2
}
```
