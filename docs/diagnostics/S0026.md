# S0026: `#else`, `#elseif` or `#endif` without `#if`

The directive continues or closes a conditional-compilation block, but no
`#if` is open: there is none before it, or an earlier `#endif` already
closed it.

## Example

```sable
module Example

fn one() -> Int {
    return 1
}

#endif
```

## Fix

```sable
module Example

fn one() -> Int {
    return 1
}
```
