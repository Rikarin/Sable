# S3104: a fuzz target's signature

A `@fuzz` function takes exactly one `U8[:]`, the bytes the fuzzer chose for this run, and is not `async`: `sable fuzz` calls it from C once an input, and waits for nothing. It fails by trapping (a failed assertion, an index out of range, a `fatalError`) or by throwing; what it returns is nothing.

## Example

```sable
module Example

import Sable.Testing

@fuzz
fn parses(_ text: String) {
    assert(text.count >= 0)
}
```

## Fix

Take the bytes, and make of them what the code under test reads.

```sable
module Example

import Sable.Testing
import Sable.Text

@fuzz
fn parses(_ data: U8[:]) {
    let text = String.fromUtf8Lossy(data)
    assert(text.count >= 0)
}
```
