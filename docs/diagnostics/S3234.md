# S3234: a generator wrote a file it may not

A source generator (docs/08) called `output.add(file: name, text)` with a
file it may not write:

- **A bad name.** A name is a single file's name ending in `.sb`, without
  `/`, `\` or `..`. The compiler decides the directory:
  `target/generated/<package>/<generator>/`.
- **A name used twice.** Within one package, each file a generator writes
  needs its own name. Put the type's name in it, as in
  `"\(declaration.name).json.sb"`.
- **A `module` line.** The compiler puts the file in the module of the
  declaration it was written for, and starts it with that module's line and
  the imports of the declaration's file. The generator writes only
  declarations, and any imports of its own.

The error is reported at the attribute that started the run. The file is
not compiled. The generator's other files are.
