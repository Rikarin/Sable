Sable is a C#-shaped language with **value types**, ARC, and regions, compiled
ahead of time through LLVM. This site is built by a program written in it.

## What it looks like

```sable
@main
fn main() {
    print("Hello, world")
}
```

Read [the overview](https://example.com/docs/01) for the long version, or
carry on to the [memory model](memory.html).

> Write the library in the language, and the language finds out what it
> is missing.
