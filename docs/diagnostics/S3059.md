# S3059: moving a `@noncopy` value out of a field or element

A `@noncopy` value stored in a field or an array element cannot be moved out
on its own: that would leave a hole in the value that holds it, which is
still alive and will still be destroyed. Move the whole containing value, or
read what you need from the field in place.

## Example

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

struct Holder {
    var handle: Handle
}

fn close(consuming h: Handle) { }

@main
fn main() {
    let holder = Holder { handle: Handle { id: 1 } }
    close(holder.handle)
}
```

## Fix

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

struct Holder {
    var handle: Handle
}

fn finish(consuming holder: Holder) { }

@main
fn main() {
    let holder = Holder { handle: Handle { id: 1 } }
    print(holder.handle.id)
    finish(holder)
}
```
