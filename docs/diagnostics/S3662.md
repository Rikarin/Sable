# S3662: a format option the value's type would ignore

Some parts of a format spec mean something only to some values:

- a sign (`+`, a space), `#`, `0` and a separator (`,` or `_`) are for a
  number, and not for a `String`, a `Char` or a `Bool`, nor for `?`, which
  writes the value as `Debug` describes it;
- a precision is for a float (digits after its point) or a `String` (how
  many of its scalars are kept), and not for an integer, a `Char` or a `Bool`;
- `#` writes an integer's radix prefix, so it goes with `x`, `X`, `o` or `b`,
  and for a float it keeps the trailing zeros that `g` and `G` drop.

Anything else would be ignored, so it is refused.

## Example

```sable
module Example

fn show(_ count: Int) -> String {
    return "\(count:.2)"
}
```

## Fix

Say what the integer is to look like — padded to a width, here — or convert
it to a float if it is to have digits after a point.

```sable
module Example

fn show(_ count: Int) -> String {
    return "\(count:>6)"
}
```
