# S7001: no builtin of that name

A `@builtin("name")` declaration names a builtin the compiler does not
have. Each builtin is a fixed operation with a fixed signature, listed in the
compiler's table (`SilBuiltins`), and the name must be one of them exactly.

Only `Sable.Core` may declare builtins, and anywhere else S3081 stops the
program first, so this is met only while working on the core library.
Correct the name or, for an operation the compiler does not have yet, add it
to the table along with its lowering.

A builtin family (`@builtin("count_leading_zeros_Self")`, see S3082) is
checked for each built-in type that conforms to its protocol: the builtin
with the type's name in place of `Self` must exist, and agree with the
declaration, for every one of them. It is also reported where a family's
member is used on a type that has no builtin of it.
