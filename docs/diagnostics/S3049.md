# S3049: a `rethrows` function that throws on its own

A caller of a `rethrows` function relies on it throwing only when a closure
it was given throws: pass a closure that cannot throw and the call cannot
either. So the body may throw only through calls to its own closure
parameters. A `throw` statement, or a call to some other throwing function,
would break that promise.

## Example

```sable
module Example

union IoError { NotFound }

fn risky() throws(IoError) -> Int { return 1 }

fn withRetry(_ body: () throws(IoError) -> Int) rethrows -> Int {
    return try risky() + body()
}
```

## Fix

Handle the other error inside the function, or declare it `throws` instead
of `rethrows`.

```sable
module Example

union IoError { NotFound }

fn risky() throws(IoError) -> Int { return 1 }

fn withRetry(_ body: () throws(IoError) -> Int) throws(IoError) -> Int {
    return try risky() + body()
}
```
