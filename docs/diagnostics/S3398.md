# S3398: a plugin's lint failed

A warning from the lint runner. A lint from a plugin threw an exception
while it looked at a file, so what it would have found there is not
reported; the other lints ran as usual, and the check goes on. The message
names the lint and the exception.

This is a bug in the plugin, not in the program: report it to the plugin's
authors, with the file. Until it is fixed, `[lints] name = "allow"` turns the
lint off.
