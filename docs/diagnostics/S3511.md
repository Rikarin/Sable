# S3511: an attribute argument that is not a constant

An attribute of the program's own — a struct conforming to `Attribute`,
written `@Route("/users")` — is made from its arguments each time reflection
is asked for it, so its arguments are constants: literals, cases, and arrays
and tuples of them. A call, a variable or a global is not.

## Example

```sable
module Example

struct Route: Attribute {
    var path: String
}

fn base() -> String {
    return "/api"
}

@Route(base())
struct Users { }
```

## Fix

```sable
module Example

struct Route: Attribute {
    var path: String
}

@Route("/api")
struct Users { }
```
