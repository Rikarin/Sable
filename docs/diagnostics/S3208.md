# S3208: `inout` on a tuple's element

`inout` says how a function is given an argument: where the caller keeps
it, to change in place. A function type's parameter may say so —
`(inout Int) -> ()` is a function that changes an Int it is handed — but a
tuple's element is a value the tuple holds, and has no caller to change
it for.

## Example

```sable
module Example

fn swapPair(_ pair: (inout Int, Int)) {}
```

## Fix

Take the element as an `inout` parameter of its own, or make the tuple
the parameter that is `inout`:

```sable
module Example

fn swapPair(_ pair: inout (Int, Int)) {
    pair = (pair.1, pair.0)
}
```
