# S6004: a function that can end without returning a value

The function declares a result, but some path through its body reaches the
closing brace without a `return` (or a `throw`, or a call that never
returns). The compiler follows every branch; a value cannot be made up for
the path that has none.

## Example

```sable
module Example

fn sign(_ n: Int) -> Int {
    if n < 0 {
        return -1
    } else if n > 0 {
        return 1
    }
}
```

## Fix

```sable
module Example

fn sign(_ n: Int) -> Int {
    if n < 0 {
        return -1
    } else if n > 0 {
        return 1
    }
    return 0
}
```
