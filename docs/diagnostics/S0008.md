# S0008: an escape sequence the language does not have

A backslash in a string or character literal starts an escape, and the
character after it is not one Sable recognises. The escapes are `\n`, `\r`,
`\t`, `\0`, `\\`, `\"`, `\'`, `\u{...}` and `\(` for interpolation. For a
literal backslash write `\\`, or use a raw string, `#"..."#`, in which a
backslash is just a backslash.

## Example

```sable
module Example

fn path() -> String {
    return "C:\Temp"
}
```

## Fix

```sable
module Example

fn path() -> String {
    return "C:\\Temp"
}
```
