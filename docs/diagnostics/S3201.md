# S3201: a constant that cannot be computed

A `const` is computed while the program is compiled, and a `comptime` block
run then (SYNTAX.md §21). When that traps — an integer overflows, a division
is by zero, a loop runs past the interpreter's step limit — the program has
no value to give it, and the compile stops where the constant or block is.
So does a constant defined in terms of itself, and an integer literal too
large for the constant's type.

## Example

```sable
module Example

const fn mean(_ total: Int, _ count: Int) -> Int => total / count

const Average: Int = mean(10, 0)
```

## Fix

```sable
module Example

const fn mean(_ total: Int, _ count: Int) -> Int => count == 0 ? 0 : total / count

const Average: Int = mean(10, 0)
```
