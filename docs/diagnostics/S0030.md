# S0030: a `#warning` directive

The program reached a `#warning` directive, which reports its message as a
warning wherever it is compiled. The build goes on. A `#warning` in a
conditional block that is left out reports nothing.

## Example

```sable
module Example

#warning "the cache is not used yet"

fn one() -> Int {
    return 1
}
```

## Fix

Remove the directive once what it points at is done.

```sable
module Example

fn one() -> Int {
    return 1
}
```
