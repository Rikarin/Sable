# S3004: a value of the wrong type

A value was used where a different type is expected: assigned to an annotated
binding, returned from a function, passed as an argument, or stored in a
field. Sable converts implicitly only where nothing can be lost or
misread — an `Int` never silently becomes a `String`, nor an `F64` an `Int`.

## Example

```sable
module Example

fn describe() -> String {
    let count: Int = "three"
    return "\(count)"
}
```

## Fix

Give the binding a value of its type, or convert explicitly.

```sable
module Example

fn describe() -> String {
    let count: Int = 3
    return "\(count)"
}
```
