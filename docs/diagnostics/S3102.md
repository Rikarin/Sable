# S3102: a test or benchmark that returns a value

A `@test` or `@bench` function returns nothing. A test fails by failing an assertion (or, if it is declared `throws`, by throwing); what it returned would have nowhere to go.

## Example

```sable
module Example

import Sable.Testing

@test
fn parses() -> Bool {
    return 2 + 2 == 4
}
```

## Fix

Assert instead of returning.

```sable
module Example

import Sable.Testing

@test
fn parses() {
    assert(2 + 2 == 4)
}
```
