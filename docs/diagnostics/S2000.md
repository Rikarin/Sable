# S2000: a name declared twice in the same scope

Two declarations in one scope have the same name: two types or functions in
a module, two fields in a type, two parameters, or two locals in one block.
A local in a nested block may shadow one outside it, but not one in its own
block. Functions with different parameter labels or types are overloads,
not duplicates.

## Example

```sable
module Example

fn sum() -> Int {
    let total = 1
    let total = 2
    return total
}
```

## Fix

Give the second one its own name, or assign to the first if it is a `var`.

```sable
module Example

fn sum() -> Int {
    var total = 1
    total = 2
    return total
}
```
