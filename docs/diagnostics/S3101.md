# S3101: a generic test or benchmark

The harness calls a `@test` or `@bench` function with no type arguments, so it cannot be generic. Write the generic code as an ordinary function, and test it through concrete types.

## Example

```sable
module Example

import Sable.Testing

@test
fn roundTrips<T>() {
    assert(true)
}
```

## Fix

Make the generic part a helper, and test each type you care about.

```sable
module Example

import Sable.Testing

fn same<T: Equatable>(_ value: T) -> Bool {
    return value == value
}

@test
fn roundTrips() {
    assert(same(1))
    assert(same("one"))
}
```
