# S3053: a conformance declared twice

A type conforms to a protocol at most once: a second declaration, in the same
list or in an extension, would give two sets of members that both claim to be
the conformance. Remove the repeat.

## Example

```sable
module Example

protocol Shape { fn area() -> F64 }

struct Square: Shape {
    var s: F64
    fn area() -> F64 { return s * s }
}

extension Square: Shape { }
```

## Fix

```sable
module Example

protocol Shape { fn area() -> F64 }

struct Square: Shape {
    var s: F64
    fn area() -> F64 { return s * s }
}
```
