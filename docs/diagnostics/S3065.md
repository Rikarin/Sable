# S3065: an override that changes the signature

An override is called wherever the member it replaces is: code that holds a
`Base` and calls `b.measure(1)` reaches the subclass's method, and reads its
result as the `Base` declares it. So an override keeps the signature of what
it replaces: the same return type, the same `throws`, `async` and `static`,
and for a property the same type, with a setter if the base has one.

## Example

```sable
module Example

open class Shape {
    open fn sides() -> Int {
        return 0
    }
}

class Square: Shape {
    override fn sides() -> String {
        return "four"
    }
}
```

## Fix

Keep the base's signature, or give the new member a name of its own.

```sable
module Example

open class Shape {
    open fn sides() -> Int {
        return 0
    }
}

class Square: Shape {
    override fn sides() -> Int {
        return 4
    }
}
```
