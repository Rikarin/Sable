# S3510: an alignment larger than 16

`@align(n)` makes a struct start at a multiple of `n` bytes wherever a value
of it is: in a frame, in a global, in another struct, in an array, in an
object. The runtime allocates every object and every array's storage aligned
to 16 bytes, so a value inside one could not be aligned to more, and
`@align` takes at most 16.

## Example

```sable
module Example

@align(64)
struct Line {
    var bytes: Int
}
```

## Fix

```sable
module Example

@align(16)
struct Line {
    var bytes: Int
}
```
