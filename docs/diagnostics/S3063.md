# S3063: an integer literal does not fit its type

An integer literal takes the type its context asks for, and that type must
be able to hold it: an `I8` holds -128 through 127, a `U8` 0 through 255, an
`Int` 64 signed bits. A literal outside its type's range would have to be
cut down to fit, silently changing its value, so it is an error instead.

## Example

```sable
module Example

@main
fn main() {
    let level: I8 = 200
    print(level)
}
```

## Fix

Choose a type wide enough for the value, or a value the type can hold.

```sable
module Example

@main
fn main() {
    let level: I16 = 200
    print(level)
}
```
