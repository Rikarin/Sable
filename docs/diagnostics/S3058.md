# S3058: copying a `@noncopy` value

A `@noncopy` value has exactly one owner at a time, so it can be moved but
never copied. This error is reported where a use would need a copy: most
often a parameter taken the ordinary way, which is only borrowed for the call
and so cannot be moved on. Take such a parameter as `consuming` to receive
ownership, or leave the value where it is and lend it.

## Example

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

fn close(consuming h: Handle) { }

fn finish(_ h: Handle) {
    close(h)
}
```

## Fix

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

fn close(consuming h: Handle) { }

fn finish(consuming h: Handle) {
    close(h)
}
```
