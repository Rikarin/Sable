# S2003: a name that two imported modules both declare

The name is not declared in this module, and more than one imported module
declares a public type by it, so the compiler cannot tell which is meant.
The message names both candidates.

A declaration in the current module always wins over imported ones, so
this only happens between imports. Write the name qualified with its
module, or import only the names needed from one of the modules.

Showing this takes two modules of your own, which a single-file example
cannot have.
