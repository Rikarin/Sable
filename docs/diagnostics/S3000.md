# S3000: the wrong number of type arguments

A generic type or generic alias was written with more or fewer type
arguments than it declares type parameters. `Box<Item>` takes exactly one,
so `Box<Int, Int>` is rejected; a type that is not generic at all, such as a
plain struct, takes none, and writing `Point<Int>` is reported here too.

## Example

```sable
module Example

struct Box<Item> { var item: Item }

fn unbox(_ b: Box<Int, Int>) { }
```

## Fix

Give one type argument for each type parameter.

```sable
module Example

struct Box<Item> { var item: Item }

fn unbox(_ b: Box<Int>) { }
```
