# S3024: not a protocol

A place that needs a protocol was given some other type. A struct, union or
enum can only conform to protocols, so listing another struct after its `:`
is an error; the same holds for generic constraints. A class may list one
base class first, and only protocols after it.

## Example

```sable
module Example

struct Point { var x: Int }

struct Labelled: Point {
    var label: String
}
```

## Fix

Hold the other struct as a field instead.

```sable
module Example

struct Point { var x: Int }

struct Labelled {
    var point: Point
    var label: String
}
```
