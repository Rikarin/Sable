# S6003: a `match` that does not cover every value

A `match` must handle every value its subject can have: every case of a union
or enum, both `true` and `false`, and for types with too many values to list
(integers, strings) a `default` arm or a binding that catches the rest. The
compiler checks this so that adding a case to a union points you at every
`match` that has to deal with it, instead of failing at run time.

## Example

```sable
module Example

enum Direction { North, South, East, West }

fn isVertical(_ d: Direction) -> Bool {
    return match d {
        case .North => true
        case .South => true
    }
}
```

## Fix

Handle the missing cases, or add a `default` arm when the rest are all
handled the same way.

```sable
module Example

enum Direction { North, South, East, West }

fn isVertical(_ d: Direction) -> Bool {
    return match d {
        case .North => true
        case .South => true
        case .East => false
        case .West => false
    }
}
```
