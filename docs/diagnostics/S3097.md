# S3097: an `@immutable` class that can change

`@immutable` says a class's objects never change once made, all the way
down, which is what lets one be shared between tasks freely. So every
stored property is a `let`, and what it holds cannot change either: a
value, an actor (whose state only it changes, one call at a time), or an
object of another `@immutable` class — directly, or through an optional or
an array.

## Example

```sable
module Example

@immutable
class Point {
    var x: Int = 0
}
```

## Fix

```sable
module Example

@immutable
class Point {
    let x: Int = 0
}
```
