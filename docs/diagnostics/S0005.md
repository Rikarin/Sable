# S0005: a raw string that never ends

A raw string opened with `#"` ends only at `"#`, with as many `#` signs as it
opened with; a lone `"` inside does not close it. The end of the file came
before the closing delimiter.

## Example

```sable
module Example

fn folder() -> String {
    return #"C:\Users\Public"
}
```

## Fix

```sable
module Example

fn folder() -> String {
    return #"C:\Users\Public"#
}
```
