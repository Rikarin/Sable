# S3300: a local binding nothing reads

The `unused_local` lint, a warning by default. A `let` or `var`, a loop
variable, or a name bound by `if let`, a match arm or a destructuring is never
read. Assigning to it does not count as reading it. Often the binding is left
over from an edit, or the code meant to use it and uses something else.

A name starting with `_`, or `_` itself, says the value is not needed, and is
never reported. `@allow(unused_local)` on a declaration turns the lint off
inside it; `[lints] unused_local = "allow"` turns it off for a package.

## Example

```sable
module Example

fn area(_ width: Int, _ height: Int) -> Int {
    let perimeter = 2 * (width + height)
    return width * height
}
```

## Fix

```sable
module Example

fn area(_ width: Int, _ height: Int) -> Int {
    return width * height
}
```
