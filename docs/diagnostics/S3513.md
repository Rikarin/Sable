# S3513: an attribute written twice

An attribute says something of a declaration once. Written a second time it
would either repeat itself or, as `@inline(always)` beside `@inline(never)`
does, contradict itself, so it is refused. The attributes that name a list
of things — `@derive`, and the lint levels `@allow` and `@warn` — may be
written more than once, as may an attribute of the program's own (a struct
conforming to `Attribute`).

## Example

```sable
module Example

@inline(always)
@inline(never)
fn twice(_ n: Int) -> Int {
    return n * 2
}
```

## Fix

```sable
module Example

@inline(never)
fn twice(_ n: Int) -> Int {
    return n * 2
}
```
