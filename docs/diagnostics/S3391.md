# S3391: a place assigned its own value

The `self_assignment` lint, a warning by default. An assignment gives a
variable, a parameter or a stored field the value it already has — `x = x`,
`self.count = self.count` — so it changes nothing. Usually another value was
meant: a parameter of the same name as the field, written without `self.`
on one side, or a name mistyped as the one beside it.

A computed property is not reported, since its setter may do something; nor
is an element, `xs[i] = xs[j]`, whose indices may differ. `sable fix`
deletes the line.

## Example

```sable
module Example

fn clamp(_ value: Int, _ high: Int) -> Int {
    var result = value
    if result > high {
        result = result
    }
    return result
}
```

## Fix

```sable
module Example

fn clamp(_ value: Int, _ high: Int) -> Int {
    var result = value
    if result > high {
        result = high
    }
    return result
}
```
