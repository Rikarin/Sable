# S3051: `some P` returning different types

A result type `some P` stands for one concrete type that conforms to `P`,
chosen by the function and hidden from its callers. The compiler still knows
which type it is, and lays out and calls it directly, so every `return` must
give that same type. Returning a `Circle` on one path and a `Square` on
another needs a value that can be either: `any P`.

## Example

```sable
module Example

protocol Shape { fn area() -> F64 }
struct Circle: Shape { var r: F64, fn area() -> F64 { return 3.0 * r * r } }
struct Square: Shape { var s: F64, fn area() -> F64 { return s * s } }

fn make(_ round: Bool) -> some Shape {
    if round { return Circle(r: 1.0) }
    return Square(s: 1.0)
}
```

## Fix

Return `any Shape`, which holds a value of any conforming type.

```sable
module Example

protocol Shape { fn area() -> F64 }
struct Circle: Shape { var r: F64, fn area() -> F64 { return 3.0 * r * r } }
struct Square: Shape { var s: F64, fn area() -> F64 { return s * s } }

fn make(_ round: Bool) -> any Shape {
    if round { return Circle(r: 1.0) }
    return Square(s: 1.0)
}
```
