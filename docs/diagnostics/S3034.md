# S3034: an async call without `await`

A call to an async function must be marked with `await`, which shows where
the current task may be suspended.

## Example

```sable
module Example

async fn fetch(_ key: String) -> String { return key }

async fn load() -> String {
    return fetch("a")
}
```

## Fix

```sable
module Example

async fn fetch(_ key: String) -> String { return key }

async fn load() -> String {
    return await fetch("a")
}
```
