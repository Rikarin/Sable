# S3060: a reference to a value with no address

A reference (`T&`, a result's or a parameter's too) points at storage that already exists:
a variable, a parameter, or a field or element of one. A temporary, such as
the result of a call, an arithmetic expression or a literal, exists only for
the expression that made it, so there is nothing for a reference to point at.

## Example

```sable
module Example

struct Point {
    var x: Int
}

fn origin() -> Point& {
    return Point { x: 0 }
}
```

## Fix

Return the value itself, or a reference into something the caller passed in.

```sable
module Example

struct Point {
    var x: Int
}

fn origin() -> Point {
    return Point { x: 0 }
}
```
