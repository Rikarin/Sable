# S3045: constructing an abstract class

An `abstract` class exists only to be subclassed: it may leave members for
its subclasses to supply, so it has no values of its own. Construct one of
its concrete subclasses instead.

## Example

```sable
module Example

abstract class Shape {
    init() { }
}

fn make() -> Shape {
    return Shape()
}
```

## Fix

```sable
module Example

abstract class Shape {
    init() { }
}

class Square: Shape {
    init() { }
}

fn make() -> Shape {
    return Square()
}
```
