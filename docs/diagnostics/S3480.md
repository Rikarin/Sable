# S3480: `yield` outside a generator

`yield` gives a generator's next element, so it is written only in the body
of a generator: a function, method, computed property or closure whose result
is `some Sequence<T>` or `some Iterator<T>` — or, `async`, `some
AsyncSequence<T>` or `some AsyncIterator<T>` (SYNTAX.md §5, "Generators").
The result has to name what is yielded, `T`, and an `async` body's elements
are waited for, so its result is an async sequence; one that is not `async`
gives a sequence that is not. An initialiser, a deinitialiser and a subscript
cannot yield.

## Example

```sable
module Example

fn evens(upTo n: Int) -> Int[] {
    var i = 0
    while i <= n {
        yield i
        i += 2
    }
}
```

## Fix

Return the sequence the yields make, naming its element:

```sable
module Example

fn evens(upTo n: Int) -> some Sequence<Int> {
    var i = 0
    while i <= n {
        yield i
        i += 2
    }
}
```
