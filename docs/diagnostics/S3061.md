# S3061: a reference that outlives what it refers to

Every reference has a root: the variable, parameter or region whose storage
it points into. The compiler infers roots (nothing is written for them) and
rejects a reference that could be used after its root is gone: returned from
the function that owns the local it points into, kept past the end of the
block that declared its root, used after its root was moved out, reset or
changed in a way that may move its bytes, or stored into a region other than
its own. The message names the root and when it ended.

## Example

```sable
module Example

struct Pair {
    var name: String
    var count: Int
}

fn label() -> String& {
    let tmp = Pair { name: "x", count: 1 }
    return &tmp.name
}
```

## Fix

Return the value, or a reference rooted in something the caller owns, such as
a parameter taken by reference.

```sable
module Example

struct Pair {
    var name: String
    var count: Int
}

fn label(_ pair: Pair&) -> String& {
    return &pair.name
}
```
