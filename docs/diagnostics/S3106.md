# S3106: more than one of a test, a benchmark and a fuzz target

A function is one of a test, a benchmark and a fuzz target, not more: `sable test`, `sable bench` and `sable fuzz` call them differently and judge them differently.

## Example

```sable
module Example

import Sable.Testing

@test @bench
fn sorts() {
    assert(true)
}
```

## Fix

Keep one attribute; write the other as a function of its own.

```sable
module Example

import Sable.Testing

@test
fn sorts() {
    assert(true)
}
```
