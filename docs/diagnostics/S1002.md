# S1002: an expression was expected

The parser needed a value here, after an operator, an `=`, a `,` in a list
or an opening bracket, and found something that cannot start an
expression: a closing bracket, another operator, a keyword that starts a
statement, or the end of the line.

The parser puts an empty name in place of the missing expression and goes
on, so the same spot is usually reported a second time as `no symbol named
''` (S2002). That second error goes away with this one. For example,
`return (a + )` needs an operand after the `+`, and `let limit: Int =`
needs a value after the `=`.
