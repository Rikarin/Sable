# S3516: an `@autoclosure` parameter passed on uncalled

Inside the function, an `@autoclosure` parameter is a closure, a
`() -> T`. Another `@autoclosure` parameter wants a `T` written at the
call, so passing the parameter itself is passing a closure where its value
is wanted. Call it: `check(c())` makes a new closure whose body calls `c`,
so the value is still worked out only when — and if — it is asked for.

## Example

```sable
module Example

fn check(_ condition: @autoclosure () -> Bool) {
    assert(condition)
}
```

## Fix

```sable
module Example

fn check(_ condition: @autoclosure () -> Bool) {
    assert(condition())
}
```
