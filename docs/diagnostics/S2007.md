# S2007: a file without a module declaration

A source file that declares anything must begin with a `module` declaration
naming the module its declarations belong to. The file is still parsed and
checked, but its declarations have nowhere to live without one.

## Example

```sable
fn one() -> Int {
    return 1
}
```

## Fix

```sable
module Example

fn one() -> Int {
    return 1
}
```
