# S1006: a pattern was expected

After `case`, in a `match` arm or an `if case`, and in the other places a
pattern may stand, the parser needed a pattern, such as a literal, a
binding like `let x`, an enum case like `.North`, or `_`, and found
something that cannot start one.

## Example

```sable
module Example

fn describe(_ n: Int) -> String {
    if case = n {
        return "zero"
    }
    return "other"
}
```

## Fix

```sable
module Example

fn describe(_ n: Int) -> String {
    if case 0 = n {
        return "zero"
    }
    return "other"
}
```
