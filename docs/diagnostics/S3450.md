# S3450: reflection in a program built without it

The program is built with `--deny-reflection`, and it asks a value or a type
about itself: `Mirror(of:)`, `TypeInfo.of(T.self)`, or one of the `Reflect`
questions they are written over. A program built so carries no reflection
(docs/06 §6.1): the runtime's field descriptors have no names, and nothing
can list a type's fields, name its cases or describe its declaration.

This is the embedded build's promise, so the compiler refuses the use rather
than quietly including what it costs. Printing a value — `print(point)`,
`"\(point)"` — is not reflection and is still allowed.

Either remove the use, writing out what it found (a `description` of your
own, a `switch` over the cases), or build without `--deny-reflection`.
