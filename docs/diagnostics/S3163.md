# S3163: a result of an opened type that cannot be erased

A call that opens a `Type` as a generic function's `T` (S3162 says when it
can) gives back a result of `T` as the existential of `T`'s protocols: for
`make<T: Zero>(_: T.Type) -> T`, `make(t)` is an `any Zero`. A result of
`T.Type` is a `Type`, and one that does not mention `T` is as it is.

Nothing else that mentions `T` can be given back — `T?`, `T[]`, `(T, Int)`,
`Box<T>` — and neither can a `T` with no protocol to be erased to, nor an
error of type `T`, since nothing at the call knows what `T` is.

## Example

```sable
module Example

protocol Zero {
    static fn zero() -> Self
}

fn zeros<T: Zero>(_ type: T.Type, count: Int) -> T[>..] {
    var made: T[>..] = []
    for _ in 0..<count {
        made.append(T.zero())
    }

    return made
}

fn build(_ t: Type) {
    let made = zeros(t, count: 3)
}
```

## Fix

Give back what can be erased — each element as `any Zero` — or what does
not mention `T`.

```sable
module Example

protocol Zero {
    static fn zero() -> Self
}

fn zero<T: Zero>(_ type: T.Type) -> T {
    return T.zero()
}

fn build(_ t: Type) {
    var made: (any Zero)[>..] = []
    for _ in 0..<3 {
        made.append(zero(t))
    }
}
```
