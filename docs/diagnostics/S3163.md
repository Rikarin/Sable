# S3163: a result of an opened type that cannot be erased

A call that opens a `Type` as a generic function's `T` (S3162 says when it
can) gives back a result of `T` as the existential of `T`'s protocols: for
`make<T: Zero>(_: T.Type) -> T`, `make(t)` is an `any Zero` (an `any Any`
when `T` has no protocols), a `T?` an `(any Zero)?` and an array of `T` an
array of `any Zero`. A result of `T.Type` is a `Type`, and one that does not
mention `T` is as it is.

Nothing else that mentions `T` can be given back — `(T, Int)`, `Box<T>` —
nor an error of type `T`, since nothing at the call knows what `T` is.

## Example

```sable
module Example

protocol Zero {
    static fn zero() -> Self
}

fn zeros<T: Zero>(_ type: T.Type) -> (T, Int) {
    return (T.zero(), 1)
}

fn build(_ t: Type) {
    let made = zeros(t)
}
```

## Fix

Give back what can be erased — the value, as `any Zero` — or what does
not mention `T`.

```sable
module Example

protocol Zero {
    static fn zero() -> Self
}

fn zero<T: Zero>(_ type: T.Type) -> T {
    return T.zero()
}

fn build(_ t: Type) {
    let made = (zero(t), 1)
}
```
