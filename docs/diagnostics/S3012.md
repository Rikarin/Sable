# S3012: indexing something that cannot be indexed

Subscript syntax `x[i]` was applied to a value whose type declares no
subscript, or with a different number of indices than the subscript takes.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn first(_ p: Point) -> Int {
    return p[0]
}
```

## Fix

```sable
module Example

struct Point { var x: Int, var y: Int }

fn first(_ p: Point) -> Int {
    return p.x
}
```
