# S1012: `typealias` is spelled `alias`

Sable has one way to name a type: `alias`. It is what Swift writes as
`typealias`, including where a conforming type gives a protocol's
`associatedtype` its type. `typealias` is reserved so that code written in
Swift's spelling is pointed here; it is read as the `alias` it meant.

## Example

```sable
module Example

protocol Container {
    associatedtype Element
    fn first() -> Element
}

struct Box: Container {
    typealias Element = Int
    fn first() -> Element { return 7 }
}
```

## Fix

```sable
module Example

protocol Container {
    associatedtype Element
    fn first() -> Element
}

struct Box: Container {
    alias Element = Int
    fn first() -> Element { return 7 }
}
```
