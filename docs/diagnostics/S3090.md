# S3090: '^0' is the end, not an element

`^n` counts a position back from a collection's end: `^1` is the last
element, `^2` the one before it. `^0` is the end itself, the position just
past the last element. It is a bound a range may stop at, `xs[1..<^0]`, but
there is no element there, so reading `xs[^0]` would always trap; written
as an index, it is refused.

## Example

```sable
module Example

fn last(_ xs: Int[:]) -> Int {
    return xs[^0]
}
```

## Fix

```sable
module Example

fn last(_ xs: Int[:]) -> Int {
    return xs[^1]
}
```
