# S6009: a pattern that might not match, in a `let` or `var`

A `let` or `var` with a pattern, such as `let (a, b) = pair`, must bind its
names whatever the value is, because the code after it uses them
unconditionally. A pattern that can fail to match (a literal, a union case, a
range) has no names to give when it fails. Use `if case` or `guard case`,
which say what happens then.

## Example

```sable
module Example

fn pair() -> (Int, String) {
    return (1, "one")
}

fn label() -> String {
    let (1, text) = pair()
    return text
}
```

## Fix

```sable
module Example

fn pair() -> (Int, String) {
    return (1, "one")
}

fn label() -> String {
    if case (1, let text) = pair() {
        return text
    }
    return "other"
}
```
