# S3098: a cast to a type held in a value

`x is T`, `x as? T`, `x as! T` and `x as T` are to a type written out: the
compiler checks the cast and gives the result that type. A name that is a
value holding a type — a `Type`, such as `type(of: y)` gives, or a `T.Type`
— is not one, since the type it holds may be known only when the program
runs, and nothing could say what type `x as? t` has.

A type known at run time tests a value with `isInstance`: whether the
value's dynamic type is that type, a subclass of it, or conforms to each
protocol of an existential. `isSubtype(of:)` asks the same of two types.

## Example

```sable
module Example

fn matches(_ value: Int, _ wanted: Type) -> Bool {
    return value is wanted
}
```

## Fix

```sable
module Example

fn matches(_ value: Int, _ wanted: Type) -> Bool {
    return wanted.isInstance(value)
}
```
