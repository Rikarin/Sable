# S3140: property observers on a property that cannot have them

`willSet` and `didSet` observe the stores to a stored property: each store
calls `willSet` with the new value, stores it, then calls `didSet` with the
old one. So the property must be a `var` (a `let` is never stored to again),
declare no `get` or `set` (it is stored, not computed), not be `lazy`, and
belong to a struct, class or actor, where its storage is laid out. An
extension cannot add one, since it cannot add storage.

## Example

```sable
module Example

struct Gauge {
    let level: Int = 0 {
        didSet { print("was \(oldValue)") }
    }
}
```

## Fix

```sable
module Example

struct Gauge {
    var level: Int = 0 {
        didSet { print("was \(oldValue)") }
    }
}
```
