# S3104: an async test or benchmark

The harness calls tests and benchmarks synchronously, so they cannot be `async` yet. Async tests are planned.

## Example

```sable
module Example

import Sable.Testing

@test
async fn waits() {
    assert(true)
}
```

## Fix

Test the synchronous part, or drop `async` if the body does not await.

```sable
module Example

import Sable.Testing

@test
fn waits() {
    assert(true)
}
```
