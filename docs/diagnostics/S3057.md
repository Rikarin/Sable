# S3057: a variable used after its value was moved out

Once a value has been moved out of a variable, the variable holds nothing
until it is assigned again, so reading it is an error. A value of a
`@noncopy` type moves whenever it is used by value: bound to another name,
or passed to a `consuming` parameter. Any value moves with an explicit
`move`. The message names where the move happened; a move inside a loop
counts as a move on every iteration after the first.

## Example

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

fn close(consuming h: Handle) { }

@main
fn main() {
    let a = Handle { id: 1 }
    close(a)
    print(a.id)
}
```

## Fix

Use the value before it is moved, or take a new one after.

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

fn close(consuming h: Handle) { }

@main
fn main() {
    let a = Handle { id: 1 }
    print(a.id)
    close(a)
}
```
