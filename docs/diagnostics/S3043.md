# S3043: `override` with nothing to override

A method or property is marked `override`, but no base class declares one of
that name and signature. Usually the name is misspelled, the parameters differ
from the base method's, or the class does not inherit from the class that
has it.

## Example

```sable
module Example

open class Shape {
    open fn area() -> F64 {
        return 0.0
    }
}

class Square: Shape {
    override fn aera() -> F64 {
        return 4.0
    }
}
```

## Fix

```sable
module Example

open class Shape {
    open fn area() -> F64 {
        return 0.0
    }
}

class Square: Shape {
    override fn area() -> F64 {
        return 4.0
    }
}
```
