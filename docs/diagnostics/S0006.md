# S0006: an empty character literal

`''` holds nothing, but a `Char` is exactly one Unicode scalar value. There is
no empty character; for an empty piece of text, use the string `""`.

## Example

```sable
module Example

fn blank() -> Char {
    return ''
}
```

## Fix

```sable
module Example

fn blank() -> Char {
    return ' '
}
```
