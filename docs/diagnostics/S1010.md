# S1010: two statements on one line

A statement ends at the end of its line. Two statements may share a line
only with a `;` between them, so here the parser found the start of
something new where the statement should have ended.

## Example

```sable
module Example

fn sum() -> Int {
    let a = 1 let b = 2
    return a + b
}
```

## Fix

```sable
module Example

fn sum() -> Int {
    let a = 1
    let b = 2
    return a + b
}
```
