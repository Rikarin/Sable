# S0024: a multi-line string line indented less than its closing quotes

The indentation of a multi-line string's closing `"""` is removed from each
of its lines, so every line that is not blank must be indented at least that
far. A line indented less would lose some of its text.

## Example

```sable
module Example

fn banner() -> String {
    return """
        Welcome
    aboard
        """
}
```

## Fix

Indent every line at least as far as the closing quotes, or move the closing
quotes left.

```sable
module Example

fn banner() -> String {
    return """
        Welcome
        aboard
        """
}
```
