# S3017: `return` with a value where none is expected

The function or initialiser returns nothing, so `return` may only end it
early, not hand back a value. Either drop the value or declare a return type.

## Example

```sable
module Example

fn answer() {
    return 42
}
```

## Fix

```sable
module Example

fn answer() -> Int {
    return 42
}
```
