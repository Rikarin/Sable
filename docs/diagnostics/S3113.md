# S3113: a lazy property that cannot be one

A `lazy var` is computed from its initialiser the first time it is read, and
kept: the compiler gives it storage that starts empty, a getter that fills it,
and a setter. So it must be a `var` (the first read writes it), have an
initialiser (the value to compute), declare no accessors of its own (it has
the compiler's), and be a property of a struct, class or actor value, not a
static or global one.

## Example

```sable
module Example

struct Document {
    var text: String
    lazy let wordCount: Int = text.count
}
```

## Fix

```sable
module Example

struct Document {
    var text: String
    lazy var wordCount: Int = text.count
}
```
