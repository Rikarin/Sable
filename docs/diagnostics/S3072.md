# S3072: a derived conformance with a field that does not conform

A derived conformance is made from the fields' own: two values are equal when
every field is equal, the hash combines every field's hash, and so on. So
every field (or union payload) must itself conform to the protocol being
derived. The message names the first field that does not.

## Example

```sable
module Example

struct Tag {
    var name: String
}

@derive(Equatable)
struct Item {
    var id: Int
    var tag: Tag
}
```

## Fix

Derive (or write) the conformance for the field's type too.

```sable
module Example

@derive(Equatable)
struct Tag {
    var name: String
}

@derive(Equatable)
struct Item {
    var id: Int
    var tag: Tag
}
```
