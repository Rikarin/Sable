# S3661: a format kind the value's type is not written in

The letter that ends a format spec says how the value is written, and each
kind is for one sort of value: `d`, `x`, `X`, `o` and `b` write an integer;
`e`, `E`, `f`, `g`, `G` and `%` write a float; a `String`, a `Char` or a
`Bool` is written as it is. `?` — the value as `Debug` describes it — is for
anything. A kind the value's type is not written in would be ignored, so it
is refused; convert the value to the type the kind writes, if that is what
was meant.

A type of the program's own that conforms to `Formattable` decides what its
spec means, and is given any kind.

## Example

```sable
module Example

fn show(_ ratio: F64) -> String {
    return "\(ratio:x)"
}
```

## Fix

Write the float in a float's kind — or convert it to an integer first.

```sable
module Example

fn show(_ ratio: F64) -> String {
    return "\(ratio:.3e)"
}
```
