# S3014: the branches of a conditional have different types

The two branches of `condition ? a : b` produce values of unrelated types, so
the expression as a whole has no single type.

## Example

```sable
module Example

fn pick(_ flag: Bool) -> Int {
    return flag ? 1 : "two"
}
```

## Fix

```sable
module Example

fn pick(_ flag: Bool) -> Int {
    return flag ? 1 : 2
}
```
