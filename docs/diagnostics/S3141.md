# S3141: a `convenience init` that does not delegate

A `convenience init` is a shortcut: it hands the work to another of its
type's initialisers, `self.init(…)`, which sets every stored field, and then
does what it adds. One that never calls `self.init` sets the fields itself,
which is what an ordinary initialiser does.

## Example

```sable
module Example

class Node {
    var name: String
    init(name: String) { self.name = name }
    convenience init() { self.name = "root" }
}
```

## Fix

Delegate to the initialiser that sets the fields, or drop `convenience`.

```sable
module Example

class Node {
    var name: String
    init(name: String) { self.name = name }
    convenience init() { self.init(name: "root") }
}
```
