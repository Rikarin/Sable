# S3302: an import nothing uses

The `unused_import` lint, a warning by default. The file never writes the
name of anything the imported module declares — a type, a function, a value,
an operator, or a member its extensions add to another module's types — so
the import only costs compile time and misleads the reader about what the
file depends on.

## Example

```sable
module Example

import Sable.Collections

fn double(_ n: Int) -> Int {
    return n * 2
}
```

## Fix

```sable
module Example

fn double(_ n: Int) -> Int {
    return n * 2
}
```
