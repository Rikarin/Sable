# S3483: an `inout` or `out` parameter in a generator

Calling a generator runs none of its body: the call captures its arguments,
by value, and returns the sequence; the body runs later, a step at a time,
as its elements are asked for (SYNTAX.md §5, "Generators"). By then the call
has returned, and there is no caller's variable for an `inout` or `out`
parameter to change.

## Example

```sable
module Example

fn counting(_ total: inout Int) -> some Sequence<Int> {
    for i in 0..<3 {
        total += i
        yield i
    }
}
```

## Fix

Take the value, and let the caller do the counting as it iterates:

```sable
module Example

fn counting(from start: Int) -> some Sequence<Int> {
    for i in start..<start + 3 {
        yield i
    }
}
```
