# S3080: `@reflectable` on a kind of type that has no values

`@reflectable` keeps a type's description (its fields, methods and cases) in
the program so it can be looked up at run time. Only a type whose values
exist can be described that way: a struct, class, actor, union or enum. A
protocol has no values of its own, so the attribute is an error on one.

## Example

```sable
module Example

@reflectable
protocol Shape {
    fn area() -> F64
}
```

## Fix

Put the attribute on the types that conform instead.

```sable
module Example

protocol Shape {
    fn area() -> F64
}

@reflectable
struct Square: Shape {
    var side: F64

    fn area() -> F64 { return side * side }
}
```
