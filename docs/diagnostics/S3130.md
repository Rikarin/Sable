# S3130: an `if` that gives a value has no `else`

An `if` written where a value is wanted gives the last line of the branch it
takes. Without an `else` there is no branch to take when the condition is
false, and so no value.

## Example

```sable
module Example

fn label(_ n: Int) -> String {
    let size = if n > 3 { "big" }
    return size
}
```

## Fix

Give the `if` an `else`, with the value for when the condition is false.

```sable
module Example

fn label(_ n: Int) -> String {
    let size = if n > 3 { "big" } else { "small" }
    return size
}
```
