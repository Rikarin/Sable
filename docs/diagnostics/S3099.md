# S3099: a construct the type checker has no rule for

The type checker met a kind of syntax it does not know how to check. Every
construct the parser produces has a rule, so a program should never see
this: if one does, it is a bug in the compiler, and the message names the
syntax it could not check.

Please report it, with the program. Until it is fixed, the same thing
written another way, such as the expression split up or a value given a name
first with `let`, usually avoids it.
