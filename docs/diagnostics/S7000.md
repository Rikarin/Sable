# S7000: a construct the compiler cannot lower yet

The program passed every check of the language, but the stage that lowers it
to Sable's intermediate form (SIL) does not handle one of the constructs it
uses yet. This is a limit of the current compiler, not an error in the
program; the message says which construct it is. At the time of writing that
includes a `rethrows` function, a function declared with a bare `throws` (any
error) or with a union of error types such as `throws(IoError | NetError)`,
an error converted through a `From` conformance on the way out of a
function, and some members reached through an `any P` value.

Until the construct is supported, express the same thing another way: for
example, declare one error type, `throws(IoError)`, and catch an error and
throw one of that type instead of relying on a `From` conversion.
