# S3069: an actor's state changed from outside it

An actor runs one piece of its code at a time, and that is what keeps its
state free of races: only the actor changes its own stored properties.
Code outside it may read them — waiting its turn, with `await` — but not
assign to them. The same holds for a type or declaration marked
`@MainActor`, whose state belongs to the main actor.

## Example

```sable
module Example

actor Counter {
    var value: Int = 0
}

@main
async fn main() {
    let counter = Counter()
    counter.value = 5
    print(await counter.value)
}
```

## Fix

Give the actor a method that makes the change, and call it.

```sable
module Example

actor Counter {
    var value: Int = 0

    fn set(_ n: Int) {
        value = n
    }
}

@main
async fn main() {
    let counter = Counter()
    await counter.set(5)
    print(await counter.value)
}
```
