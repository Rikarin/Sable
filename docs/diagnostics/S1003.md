# S1003: a type was expected

The parser needed a type here, after the `:` of a parameter or binding, the
`->` of a function, or in a list of type arguments, and found something
that cannot start one.

## Example

```sable
module Example

fn double(_ x: ) -> Int {
    return 2
}
```

## Fix

```sable
module Example

fn double(_ x: Int) -> Int {
    return x * 2
}
```
