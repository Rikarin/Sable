# S3421: the numbers given fail a const-generic predicate

A type's `where` clause may require something of its value generic
parameters, such as `where N > 0` on `struct Buf<T, N: Int>`. The predicate
is evaluated for the numbers each instance is written with, while the
program is compiled; one that is false for them, or has no value (it divides
by zero, or overflows), is this error, at the type that gives them.

An instance written inside another generic declaration, with that one's own
value parameter passed on (`Buf<T, M>`), has no numbers to check yet, and is
not checked; only an instance written with numbers is.

## Example

```sable
module Example

struct Buf<T, N: Int> where N > 0 {
    var items: T[N]
}

fn main() {
    let b: Buf<Int, 0>? = none
    print(b == none)
}
```

## Fix

```sable
module Example

struct Buf<T, N: Int> where N > 0 {
    var items: T[N]
}

fn main() {
    let b: Buf<Int, 1>? = none
    print(b == none)
}
```
