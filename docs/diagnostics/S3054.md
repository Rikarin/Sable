# S3054: an error type the function does not declare

A function declared `throws(E)` throws only `E`. A `try` on a call that throws
some other error type `F` would let `F` escape, so it is an error unless `E`
can be made from `F`: that is what a conformance `extension E: From<F>`
declares, and with it the error is converted on the way out. Alternatives are
to widen the declaration (`throws(E | F)`, or plain `throws`), or to catch
`F` with `do`/`catch`.

## Example

```sable
module Example

union IoError { Denied }
union NetError { Timeout }

fn send(_ text: String) throws(NetError) -> String { return text }

fn save(_ text: String) throws(IoError) -> String {
    return try send(text)
}
```

## Fix

Here the function catches the `NetError` and throws an `IoError` of its own.

```sable
module Example

union IoError { Denied }
union NetError { Timeout }

fn send(_ text: String) throws(NetError) -> String { return text }

fn save(_ text: String) throws(IoError) -> String {
    do {
        return try send(text)
    } catch {
        throw IoError.Denied
    }
}
```
