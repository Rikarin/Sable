# S3030: an extension with an initialiser

An extension may not add an initialiser: initialisers belong with the type's
declaration, which knows every stored field that must be set. An extension
can add a static function that builds a value instead.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

extension Point {
    init(_ n: Int) {
        self.x = n
        self.y = n
    }
}
```

## Fix

```sable
module Example

struct Point { var x: Int, var y: Int }

extension Point {
    static fn square(_ n: Int) -> Point {
        return Point { x: n, y: n }
    }
}
```
