# S3044: inheriting from, or overriding, what is closed to it

A class marked `sealed` has no subclasses at all. A class or method that is
not marked `open` may be subclassed or overridden only inside the module that
declares it, so its author can rely on its behaviour everywhere else. This
error is reported for a subclass of a sealed class, and for a subclass or an
override, in another module, of something that is not `open`.

## Example

```sable
module Example

open class Shape { }

sealed class Circle: Shape { }

class Ring: Circle { }
```

## Fix

Inherit from a class that allows it, or drop `sealed` if the class is yours
and subclasses are wanted.

```sable
module Example

open class Shape { }

sealed class Circle: Shape { }

class Ring: Shape { }
```
