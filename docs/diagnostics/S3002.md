# S3002: a generic type without its type arguments

A generic type was named in a type position without its type arguments.
Sable does not infer the arguments of a type written in a signature or an
annotation, so `Box` alone does not say what the box holds.

## Example

```sable
module Example

struct Box<Item> { var item: Item }

fn unbox(_ b: Box) { }
```

## Fix

```sable
module Example

struct Box<Item> { var item: Item }

fn unbox(_ b: Box<Int>) { }
```
