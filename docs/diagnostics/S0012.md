# S0012: an underscore leading the digits of a number

`_` separates groups of digits in a numeric literal, so it may only stand
between digits. Here one comes first in a run of digits, as in `0x_FF`. (A
name such as `_1` is an identifier, not a number.)

## Example

```sable
module Example

fn mask() -> Int {
    return 0x_FF
}
```

## Fix

```sable
module Example

fn mask() -> Int {
    return 0xFF
}
```
