# S0021: a string interpolation that never ends

`\(` inside a string starts an interpolated expression, which runs to its
matching `)` on the same line; an interpolation cannot span lines. Here the
line ended before that `)`. In a one-line string the string ends with the
line too, so it is also reported as unterminated (S0003).

## Example

```sable
module Example

fn label(count: Int) -> String {
    return """
        count: \(count
        """
}
```

## Fix

```sable
module Example

fn label(count: Int) -> String {
    return """
        count: \(count)
        """
}
```
