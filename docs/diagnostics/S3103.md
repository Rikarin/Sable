# S3103: a test on an instance method

`@test` and `@bench` mark a function of a module or a `static` method: the harness has no value to call an instance method on.

## Example

```sable
module Example

import Sable.Testing

struct Counter {
    var count: Int

    @test
    fn startsAtZero() {
        assertEqual(Counter(count: 0).count, 0)
    }
}
```

## Fix

Make it `static`, or move it to the module.

```sable
module Example

import Sable.Testing

struct Counter {
    var count: Int

    @test
    static fn startsAtZero() {
        assertEqual(Counter(count: 0).count, 0)
    }
}
```
