# S3055: `weak` on something other than an optional class `var`

A `weak` reference does not keep its object alive, and becomes `none` when
the object is freed. So it must be a reference (a class type), it must be
optional to have somewhere to put `none`, and it must be a `var`, since the
runtime changes it.

## Example

```sable
module Example

class Owner { }

class Pet {
    weak var owner: Owner

    init(owner: Owner) {
        self.owner = owner
    }
}
```

## Fix

Make it optional (or use `unowned` if the object always outlives it).

```sable
module Example

class Owner { }

class Pet {
    weak var owner: Owner?

    init(owner: Owner) {
        self.owner = owner
    }
}
```
