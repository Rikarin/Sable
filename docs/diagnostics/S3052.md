# S3052: a type that contains itself by value

A struct (or tuple) stores its fields inline, so a struct that holds itself,
directly or through other structs, tuples or optionals, would need to be
larger than itself. An indirection breaks the chain: a class reference, an
array, or a union case, each of which stores the inner value elsewhere.

## Example

```sable
module Example

struct Node {
    var value: Int
    var next: Node?
}
```

## Fix

Hold the next node through a class (or an array, or a union).

```sable
module Example

class Node {
    var value: Int
    var next: Node?

    init(value: Int) {
        self.value = value
        self.next = none
    }
}
```
