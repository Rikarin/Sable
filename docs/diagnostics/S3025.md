# S3025: more than one base class

A class may inherit from one class at most. After the base class, the list
after `:` may name only protocols.

## Example

```sable
module Example

open class Animal { }
open class Pet { }

class Dog: Animal, Pet { }
```

## Fix

Inherit from one class, and express the other role as a protocol.

```sable
module Example

open class Animal { }
protocol Pet { }

class Dog: Animal, Pet { }
```
