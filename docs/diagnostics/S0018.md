# S0018: a byte order mark at the start of the file

The file begins with U+FEFF, a byte order mark. Sable source is UTF-8, which
has no byte order to mark, so the BOM is not allowed. Some Windows editors
add one when saving as "UTF-8 with BOM"; save the file as plain UTF-8
instead.

## Example

The file below starts with an invisible U+FEFF.

```sable
﻿module Example

fn one() -> Int {
    return 1
}
```

## Fix

```sable
module Example

fn one() -> Int {
    return 1
}
```
