# S0020: an empty escaped identifier

A pair of backquotes escapes the name between them, so that a keyword can
be used as an identifier. ` `` ` has nothing between the backquotes, and an
identifier cannot be empty.

## Example

```sable
module Example

fn ``() -> Int {
    return 1
}
```

## Fix

```sable
module Example

fn one() -> Int {
    return 1
}
```
