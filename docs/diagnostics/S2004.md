# S2004: a name that is not a type, used as one

A name was looked up as a type and found, but what it names is not a type.
Writing `Point.x` where a type is expected finds the field `x` of `Point`,
which is a value, not a type nested in `Point`. `Self` used outside a type
or an extension is reported the same way, since there is no type for it to
mean, as is a nested type looked up in something that has no nested types.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn horizontal(_ p: Point.x) -> Int {
    return 0
}
```

## Fix

```sable
module Example

struct Point { var x: Int, var y: Int }

fn horizontal(_ p: Point) -> Int {
    return p.x
}
```
