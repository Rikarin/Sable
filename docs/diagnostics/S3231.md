# S3231: a generator trapped

A source generator (docs/08) trapped while it ran for the declaration this
error points at: an index out of range, a failed `!`, an overflow, or more
steps than it is allowed. The step limit is far above what a generator
should need, so running out of steps usually means a loop that never ends.

The error is reported at the attribute that started the run, because that
is the declaration the generator was given. The other declarations are still
given to the generator, so one bad declaration does not hide problems in the
rest.

Look at what the generator assumes about the declaration. A generator that
reads `declaration.fields[0]` traps on a struct with no fields. A generator
that does not handle a declaration should say so with `output.error(...)`
(S3232) and return.
