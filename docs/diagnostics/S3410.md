# S3410: a type declared Sendable holds something that is not

A type that declares `: Sendable` (or a protocol that refines it) promises
that its values may cross an actor's boundary, and the promise is checked
where it is made: everything the type holds — each stored field, each
union case's payload, and through them their own fields, elements and
type arguments — must be Sendable.

A class is shared mutable state, and is not Sendable unless it is
`@immutable` or `@MainActor`. A field of a type parameter needs that
parameter constrained `T: Sendable`. See S3207 for what is Sendable.

## Example

```sable
module Example

class Tally {
    var count: Int = 0
}

struct Report: Sendable {
    var tally: Tally
}
```

## Fix

Hold a value instead of the class, or make the class an actor or
`@immutable`.

```sable
module Example

struct Tally {
    var count: Int
}

struct Report: Sendable {
    var tally: Tally
}
```
