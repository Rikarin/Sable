# S3108: a test declared inside a body

`@test` and `@bench` mark a function of a module or a static method. A function declared inside another function's body exists only while that body runs, so the harness cannot reach it.

## Example

```sable
module Example

import Sable.Testing

fn outer() {
    @test
    fn inner() {
        assert(true)
    }
    inner()
}
```

## Fix

Declare the test at the top level of the module.

```sable
module Example

import Sable.Testing

@test
fn inner() {
    assert(true)
}
```
