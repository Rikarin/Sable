# S3023: a type does not conform to a protocol

A type is declared to conform to a protocol but does not provide everything
the protocol asks for: a method, a property, or another requirement is
missing. The same code is used when a generic argument does not satisfy a
constraint or a type's `where` clause — written, as in `Box<NotShape>`, or
inferred from an initialiser's arguments, as in `Box(t: notShape)` — and when a
derived conformance does not hold because a field's type lacks it.

## Example

```sable
module Example

protocol Named { fn name() -> String }

struct City: Named {
    var population: Int
}
```

## Fix

Implement each requirement.

```sable
module Example

protocol Named { fn name() -> String }

struct City: Named {
    var population: Int

    fn name() -> String { return "city" }
}
```
