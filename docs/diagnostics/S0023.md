# S0023: text on the line of a multi-line string's opening quotes

A multi-line string's content starts on the line after its opening `"""`;
nothing but the end of the line may follow those quotes. Likewise the
closing `"""` sits on a line of its own, and its indentation is removed from
every line of the string.

## Example

```sable
module Example

fn banner() -> String {
    return """Welcome
"""
}
```

## Fix

```sable
module Example

fn banner() -> String {
    return """
        Welcome
        """
}
```
