# S3160: a const-generic predicate that cannot be evaluated

A `where` clause may hold a predicate over a type's value generic parameters,
such as `where N > 0` on `struct Buf<T, N: Int>`, checked for the numbers
each instance is given (docs/03 §3.4). It is evaluated while the program is
compiled, from those numbers alone, so it may be made only of the type's
value parameters, whole numbers, `true`, `false`, parentheses and the
arithmetic, comparison and logical operators.

A predicate on a declaration that has no value parameter — a type parameter
`N` without `: Int`, or a function's — has nothing to be about, and one that
names anything else (another variable, a function call) cannot be evaluated
then.

## Example

```sable
module Example

struct Buffer<T, N> where N > 0 {
    var first: T
}
```

## Fix

Make `N` a value parameter by giving it an integer type.

```sable
module Example

struct Buffer<T, N: Int> where N > 0 {
    var first: T
}
```
