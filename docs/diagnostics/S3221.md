# S3221: a constant that cannot be computed

A `const` is computed while the program is compiled, and a `comptime` block
run then, in the compiler's interpreter (SYNTAX.md §21). When that cannot
finish — a constant is defined in terms of itself, a loop runs past the
interpreter's step limit, or the code traps for a reason other than
arithmetic — the program has no value to give it, and the compile stops
where the constant or block is. Arithmetic that overflows or divides by
zero, there or in a `const fn` it calls, is S3201.

## Example

```sable
module Example

const Width: Int = Height + 1
const Height: Int = Width + 1
```

## Fix

```sable
module Example

const Width: Int = 80
const Height: Int = Width / 2
```
