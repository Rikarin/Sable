# S3130: an open existential in a union

A structural union is closed: every case it can hold is known where it is
written, which is what lets a `match` over it be checked for exhaustiveness.
`any P` is open — any type, in any module, can conform to `P` later — so it
cannot be one of a union's cases (docs/03 §3.1). `any Error` is the one
exception, as what a throw of several error types widens to.

## Example

```sable
module Example

protocol Shape {}

fn describe(_ value: Int | any Shape) {}
```

## Fix

Name the types the union holds, or take the protocol on its own.

```sable
module Example

protocol Shape {}

struct Circle: Shape {}

fn describe(_ value: Int | Circle) {}
```
