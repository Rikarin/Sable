# S3304: a local that hides a parameter

The `shadowed_parameter` lint, a warning by default. A `let` or `var` in the
body has the same name as one of the function's parameters, so from there on
the name means the local, and the parameter cannot be reached. That is legal,
and sometimes meant, but it is easy to read the wrong one.

Unwrapping in place — `if let value = value`, `guard let value = value` — is
the idiom, and is not reported.

## Example

```sable
module Example

fn clamp(_ value: Int, _ limit: Int) -> Int {
    let value = value > limit ? limit : value
    return value
}
```

## Fix

Give the new value its own name.

```sable
module Example

fn clamp(_ value: Int, _ limit: Int) -> Int {
    let clamped = value > limit ? limit : value
    return clamped
}
```
