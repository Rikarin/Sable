# S3392: a private declaration nothing uses

The `unused_private` lint, a warning by default. A `private` function or
type is named nowhere outside its own declaration. Nothing outside the
declaration around it can reach it, so nothing can use it: it is left over,
or what was meant to call it calls something else. A function that only
calls itself is unused too.

Not reported: a function whose signature something else decides (an
override, a protocol's requirement, `main`); one the harness or other code
calls (`@test`, `@bench`, `@export`, `@extern`); operators, initialisers and
accessors, which are used without being named; and a name starting with `_`.

## Example

```sable
module Example

public struct Price {
    var cents: Int

    public fn text() -> String {
        return "\(cents / 100)"
    }

    private fn rounded() -> Int {
        return cents / 100 * 100
    }
}
```

## Fix

Delete it, or use it.

```sable
module Example

public struct Price {
    var cents: Int

    public fn text() -> String {
        return "\(cents / 100)"
    }
}
```
