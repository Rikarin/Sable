# S3096: a declaration not available on this platform

`@available(macos, linux)` says which platforms a declaration exists on.
Using it in a build for any other platform is an error, so that code meant
for one system does not reach another by accident. A version written with a
platform, `@available(macos: "14.0")`, is recorded but not yet checked.

## Example

```sable
module Example

@available(windows)
fn registryKey() -> String {
    return "HKEY_CURRENT_USER"
}

fn settings() -> String {
    return registryKey()
}
```

## Fix

```sable
module Example

@available(windows)
fn registryKey() -> String {
    return "HKEY_CURRENT_USER"
}

@available(windows)
fn settings() -> String {
    return registryKey()
}
```
