# S3066: a cast that cannot be made

`as` converts between numeric types, trapping when the value does not fit,
and `unchecked as` does the same but wraps or truncates instead. `as?` and
`as!` ask what a value is as the program runs: whether a `Shape` is a
`Circle`, or what an `any Drawable` holds. A cast that is none of these —
between unrelated types such as `String` and `Int`, or between classes
on different lines of inheritance, which no object can be both of — could
never succeed, so it is refused.

## Example

```sable
module Example

fn count(_ text: String) -> Int {
    return text as Int
}
```

## Fix

Say how the value becomes the other type: here, by counting its characters.

```sable
module Example

fn count(_ text: String) -> Int {
    return text.count
}
```
