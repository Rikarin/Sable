# S3006: calling something that is not callable

Call syntax `f(...)` was applied to a value that is not a function, a closure,
or a type with an initialiser. If the value is an optional function, call it
with `?()` or unwrap it first; the message says which case applies.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn horizontal(_ p: Point) -> Int {
    return p()
}
```

## Fix

```sable
module Example

struct Point { var x: Int, var y: Int }

fn horizontal(_ p: Point) -> Int {
    return p.x
}
```
