# S3067: a reference into an object's array is kept

A reference to an element of an array (`&xs[i]`), or one a `mutating`
member returns, is an address in the array's buffer, good only while the
array does not change. Rooted in a variable, it holds an access to that
variable until its last use, and the compiler checks that nothing else uses
the variable meanwhile (S3062). Rooted in an object's field, or a global,
that cannot be proved: another reference to the same object, or any
function the program calls, may grow the array and move its buffer. So such
a reference is used only where it is made, and is not kept in a variable,
passed to a call or returned.

## Example

```sable
module Example

struct Node {
    var v: Int
}

class Scene {
    var nodes: Node[>..] = [Node(v: 1)]
}

@main
fn main() {
    let scene = Scene()
    let first = &scene.nodes[0]
    first.v = 2
}
```

## Fix

Change the element where it is, or copy it out and store it back.

```sable
module Example

struct Node {
    var v: Int
}

class Scene {
    var nodes: Node[>..] = [Node(v: 1)]
}

@main
fn main() {
    let scene = Scene()
    scene.nodes[0].v = 2
    print(scene.nodes[0].v)
}
```
