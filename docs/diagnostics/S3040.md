# S3040: a member that is not visible here

The member exists, but its access level hides it from this code. A `private`
member is visible only inside the declaration that holds it, the types nested
in it, and extensions of it in the same file; an `internal` one only inside
its module.

## Example

```sable
module Example

struct Account {
    var id: Int
    private var secret: String
}

fn leak(_ account: Account) -> String {
    return account.secret
}
```

## Fix

Use what the type makes visible, or give the type a member that hands out
what callers may see.

```sable
module Example

struct Account {
    var id: Int
    private var secret: String

    fn hint() -> String {
        return "\(secret.count) characters"
    }
}

fn leak(_ account: Account) -> String {
    return account.hint()
}
```
