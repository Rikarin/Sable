# S3107: arguments to @test or @bench

`@bench` takes no arguments. `@test` takes none, or one saying the test must
trap: `@test(traps)` passes when the test traps — an index out of range, an
overflow, a `fatal` — and fails when it returns; `@test(traps: "out of
range")` also wants the trap's message to contain that text, written as a
plain string. A failed assertion is not the trap: it fails the test.

To pick which tests run, pass a filter on the command line: `sable test
sorts` runs the tests whose names contain `sorts`.

## Example

```sable
module Example

import Sable.Testing

@test("slow")
fn sorts() {
    assert(true)
}
```

## Fix

Drop the arguments, and put what they said in the name.

```sable
module Example

import Sable.Testing

@test
fn sortsSlowly() {
    assert(true)
}
```
