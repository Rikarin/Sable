# S3200: code run at compile time that cannot be

A `const`'s value, a `const fn`'s body and a `comptime` block run while the
program is compiled, in the compiler's interpreter (SYNTAX.md §21). They must
mean the same on every machine that compiles them, so they may allocate,
loop, branch and call, but what they call must be a `const fn`, something
the compiler wrote (a memberwise initialiser, a derived `==`), or a member of
`Sable.Core` that neither reads, writes nor waits. They may not use `unsafe`,
`await`, `print` or `Runtime`, nor read a global that is set when the program
runs (`static let`, a module-level `var`); other constants they may read.

A `comptime` block in a function body runs before the function does, so it
cannot see the function's parameters, locals or `self`.

`compileError` takes its message as a string literal.

## Example

```sable
module Example

fn square(_ n: Int) -> Int => n * n

const Area: Int = square(4)
```

## Fix

Mark the function `const fn`, so that it can run at compile time:

```sable
module Example

const fn square(_ n: Int) -> Int => n * n

const Area: Int = square(4)
```
