# S3001: type arguments on something that is not generic

Type arguments were written after a name that cannot take them: a type
parameter (`T<Int>` inside a generic function), or an alias declared without
type parameters of its own. A type parameter already stands for one complete
type, and a plain alias is only another name for its target.

## Example

```sable
module Example

alias Count = Int

fn total(_ c: Count<Int>) -> Int {
    return c
}
```

## Fix

Drop the type arguments, or declare the alias with type parameters.

```sable
module Example

alias Count = Int

fn total(_ c: Count) -> Int {
    return c
}
```
