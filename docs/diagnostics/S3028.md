# S3028: a field left out of a struct literal

A struct literal such as `Point { x: 1 }` must give every stored field that
has no default value; a value with a field never set would hold whatever
bytes happened to be there.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn origin() -> Point {
    return Point { x: 0 }
}
```

## Fix

Give the missing field a value, or a default in the struct.

```sable
module Example

struct Point { var x: Int, var y: Int }

fn origin() -> Point {
    return Point { x: 0, y: 0 }
}
```
