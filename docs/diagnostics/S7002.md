# S7002: a builtin declared with the wrong signature

A `@builtin("name")` declaration's parameters and result do not match the
builtin it names. A builtin is a fixed operation: its operands, receiver
first, and its result are given by the compiler's table (`SilBuiltins`), and
the declaration must spell exactly those, with every parameter passed by
value and no `throws`. A builtin whose first operand is an address is
declared as a `mutating` method, and only such a one. The message gives both
signatures.

Only `Sable.Core` may declare builtins, and anywhere else S3081 stops the
program first, so this is met only while working on the core library: make
the declaration match the table.
