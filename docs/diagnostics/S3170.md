# S3170: a type is constrained by itself

A constraint says what a type conforms to. One that leads back to the type it
constrains, directly, through another parameter, or through an array of itself,
says nothing of it.

## Example

```sable
module Example

fn count<A: B, B: A>(_ value: A) -> Int {
    return 1
}
```

## Fix

Constrain the parameter to a protocol or a class. A protocol's arguments may
mention the parameter: `T: Comparable<T>` is not circular.

```sable
module Example

fn count<A: Equatable, B: Equatable>(_ value: A) -> Int {
    return 1
}
```
