# S3107: arguments to @test or @bench

`@test` and `@bench` take no arguments. To pick which tests run, pass a filter on the command line: `sable test sorts` runs the tests whose names contain `sorts`.

## Example

```sable
module Example

import Sable.Testing

@test("slow")
fn sorts() {
    assert(true)
}
```

## Fix

Drop the arguments, and put what they said in the name.

```sable
module Example

import Sable.Testing

@test
fn sortsSlowly() {
    assert(true)
}
```
