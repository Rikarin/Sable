# S6007: `match` arms of different types

A `match` used as a value has one type, so every arm must produce a value of
it. When nothing outside the `match` says what that type is, the first arm
decides, and a later arm of another type is this error. A `match` used as a
statement has no such rule: its arms may be blocks that produce nothing.

## Example

```sable
module Example

enum Size { Small, Large }

fn label(_ size: Size) -> String {
    let text = match size {
        case .Small => "small"
        case .Large => 2
    }
    return text
}
```

## Fix

```sable
module Example

enum Size { Small, Large }

fn label(_ size: Size) -> String {
    let text = match size {
        case .Small => "small"
        case .Large => "large"
    }
    return text
}
```
