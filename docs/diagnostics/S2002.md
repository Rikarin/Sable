# S2002: no symbol by that name

A name was used that nothing in scope declares: not a local, a parameter, a
member of the type or `self`, a declaration in the module, nor anything an
`import` brought in. The same code is used for a member access whose type
has no member of that name.

Check the spelling, that the declaration is visible from here, and that the
module that declares it is imported.

## Example

```sable
module Example

fn area(width: Int, height: Int) -> Int {
    return width * heigth
}
```

## Fix

```sable
module Example

fn area(width: Int, height: Int) -> Int {
    return width * height
}
```
