# S1008: a declaration was expected

At the top level of a file and in the body of a type, only declarations may
appear: functions, types, properties, extensions and the like. A statement
such as `return` or a bare expression belongs inside a function body.

## Example

```sable
module Example

struct Counter {
    var count: Int
    count += 1
}
```

## Fix

```sable
module Example

struct Counter {
    var count: Int

    mutating fn increment() {
        count += 1
    }
}
```
