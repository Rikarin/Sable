# S0025: an unknown directive

A `#` at the start of a line begins a compiler directive, and this one is
not among them. The directives are `#if`, `#elseif`, `#else`, `#endif`,
`#error` and `#warning`.

## Example

```sable
module Example

#pragma once

fn one() -> Int {
    return 1
}
```

## Fix

```sable
module Example

fn one() -> Int {
    return 1
}
```
