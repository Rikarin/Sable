# S0007: a character literal holding more than one character

A `Char` is exactly one Unicode scalar value, and the literal holds several.
Text of any length is a `String`, written in double quotes. Some characters
that look like one, such as many emoji or a letter with a separate combining
accent, are made of several scalars and must be strings too.

## Example

```sable
module Example

fn ending() -> Char {
    return 'ok'
}
```

## Fix

```sable
module Example

fn ending() -> String {
    return "ok"
}
```
