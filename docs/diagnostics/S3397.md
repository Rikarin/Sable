# S3397: reported by a plugin's lint

A lint from a plugin found something. Plugins add lints of their own to
`sable check` and `sable lint` (docs/05 §5.7); every plugin's lint reports
under this code, and the lint's name at the end of the message, in
brackets, says which one it was and what to write in `@allow(...)` or the
`[lints]` table to change its level. What it means is the plugin's to say:
see its documentation.

A plugin is a .NET assembly with public classes deriving from
`Sable.Symbols.Lint`, each with a constructor that takes nothing. A package
names its plugins in its manifest, relative to the manifest:

```toml
[lints]
plugins = ["tools/house-lints.dll"]
no_print = "error"
```

`sable lint --plugin <path>` loads one for loose files, and
`sable lint --list` lists the lints it adds.
