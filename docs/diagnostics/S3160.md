# S3160: a const-generic predicate

A `where` clause may hold a predicate over a value generic parameter, such as
`where N > 0`, checked when the generic is instantiated (docs/03 §3.4). Generic
parameters take only types so far, so there is no value for such a predicate
to test, and it is an error until value generic parameters arrive. State the
requirement where the value is known instead: as a precondition in an
initialiser, for instance.

## Example

```sable
module Example

struct Buffer<T, N> where N > 0 {
    var first: T
}
```

## Fix

```sable
module Example

struct Buffer<T> {
    var first: T
}
```
