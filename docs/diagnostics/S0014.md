# S0014: an integer literal too large for 64 bits

Integer literals are read as unsigned 64-bit numbers, so no literal can
exceed 18446744073709551615 (`UInt64.max`). Whether a smaller literal fits
the type it is used as is checked afterwards, against that type.

## Example

```sable
module Example

fn big() -> F64 {
    return 100000000000000000000
}
```

## Fix

A floating-point literal can hold a value this large, approximately.

```sable
module Example

fn big() -> F64 {
    return 1e20
}
```
