# S3106: both a test and a benchmark

A function is a test or a benchmark, not both: `sable test` and `sable bench` call them differently and judge them differently.

## Example

```sable
module Example

import Sable.Testing

@test @bench
fn sorts() {
    assert(true)
}
```

## Fix

Keep one attribute; write the other as a function of its own.

```sable
module Example

import Sable.Testing

@test
fn sorts() {
    assert(true)
}
```
