# S3660: a format spec that is not one

What follows the colon in an interpolation, `"\(price:>10.2)"`, is a format
spec, and it has one form, each part optional but in this order:

    [[fill] align] [sign] [#] [0] [width] [, or _] [.precision] [kind]

`align` is `<`, `^` or `>`; `sign` is `+`, `-` or a space; `kind` is one of
`d x X o b e E f g G % ?`. A scalar where none of these can be — a letter
that names no kind, a `.` with no precision after it, a second kind — makes
the spec not one, and so does a width or a precision too large for any
string to have. The hole is then written as if it had no spec.

## Example

```sable
module Example

fn show(_ n: Int) -> String {
    return "\(n:08q)"
}
```

## Fix

Name a kind there is: `x` for hexadecimal, here.

```sable
module Example

fn show(_ n: Int) -> String {
    return "\(n:08x)"
}
```
