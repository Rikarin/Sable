# S3100: a test that takes parameters

A `@test` function is called by the harness `sable test` builds, which has nothing to pass it unless `@test(arguments: [...])` says what: an array of what the test takes (of tuples, for several parameters), or an array for each parameter. Each value is then a test of its own. The parameters are plain ones: not `inout`, variadic or `@autoclosure`.

## Example

```sable
module Example

import Sable.Testing

@test
fn addsUp(_ n: Int) {
    assertEqual(n + n, n * 2)
}
```

## Fix

Say what to run it with.

```sable
module Example

import Sable.Testing

@test(arguments: [0, 1, 7, 100])
fn addsUp(_ n: Int) {
    assertEqual(n + n, n * 2)
}
```
