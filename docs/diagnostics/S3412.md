# S3412: a default value that needs itself

A parameter's default value, or a stored property's initial value that a
memberwise initialiser defaults to, is put into each call that leaves it
off. One whose value makes such a call itself — leaving the same
parameter or property off, directly or through other defaults — would be
put in again without end, so it has no value.

A function the default calls is not looked into: what its body does
happens when it runs, not where the default is put in.

## Example

```sable
module Example

struct Size {
    var width: Int = 1
    var height: Int = Size(width: 2).height
}

fn main() {
    print(Size().width)
}
```

## Fix

Give it a value that does not leave itself off.

```sable
module Example

struct Size {
    var width: Int = 1
    var height: Int = Size(width: 2, height: 3).width
}

fn main() {
    print(Size().width)
}
```
