# S3105: a benchmark's parameters

A `@bench` function takes nothing, and then its whole body is timed, or exactly one `Bencher` (from Sable.Testing), and then only the closure it passes to `iterate` is timed, so setup can stay outside the measurement.

## Example

```sable
module Example

import Sable.Testing

@bench
fn summing(_ count: Int) {
    var total = 0
    for i in 0..<count {
        total += i
    }
}
```

## Fix

Take a `Bencher`, and do the setup outside `iterate`.

```sable
module Example

import Sable.Testing

@bench
fn summing(_ b: Bencher) {
    let count = 1000
    b.iterate(() => {
        var total = 0
        for i in 0..<count {
            total += i
        }
    })
}
```
