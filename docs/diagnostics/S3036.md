# S3036: `try` over an expression that cannot throw

This is a warning. Nothing under the `try` can throw, so the mark is
redundant and suggests an error path that does not exist. It often means the
function called was changed to stop throwing.

## Example

```sable
module Example

fn double(_ n: Int) -> Int { return n * 2 }

fn four() -> Int {
    return try double(2)
}
```

## Fix

```sable
module Example

fn double(_ n: Int) -> Int { return n * 2 }

fn four() -> Int {
    return double(2)
}
```
