# S3068: something that may not outlive the call escapes it

Two kinds of parameter are only lent for the length of a call.

A closure parameter not marked `@escaping` may be called, or passed on to
another closure parameter that is not `@escaping` either — nothing more.
Returned, stored in a field, passed to an `@escaping` parameter, or captured
by a closure that may outlive the call, it could run after the call that
lent it has ended. A closure written straight into a call, for a parameter
that is not `@escaping`, does not outlive the call; any other may.

An `inout`, `out` or `ref` parameter is the caller's own storage. No closure
may capture one: what a closure captures is kept in an object, which nothing
stops from outliving the call.

## Example

```sable
module Example

fn later(_ action: () -> Int) -> () -> Int {
    return action
}

@main
fn main() {
    let run = later(() => 42)
    print(run())
}
```

## Fix

Mark the parameter `@escaping` when the closure is meant to outlive the
call. (For a captured `inout`, copy it into a local and capture that.)

```sable
module Example

fn later(_ action: @escaping () -> Int) -> () -> Int {
    return action
}

@main
fn main() {
    let run = later(() => 42)
    print(run())
}
```
