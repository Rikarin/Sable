# S2006: no module by that name

An `import` names a module that is neither in the program nor in the
standard library. Module names are case-sensitive and dotted, such as
`Sable.Math`.

## Example

```sable
module Example

import Sable.Maths

fn greatest(_ a: Int, _ b: Int) -> Int {
    return a > b ? a : b
}
```

## Fix

```sable
module Example

import Sable.Math

fn greatest(_ a: Int, _ b: Int) -> Int {
    return max(a, b)
}
```
