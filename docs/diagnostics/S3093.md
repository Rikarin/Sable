# S3093: an attribute where it does not apply

Each attribute means something for some declarations only: `@noncopy` and
`@inline_layout` for a struct or a union, `@escaping` for a parameter of
function type, `@autoclosure` for a parameter, `@frozen` for a union, `@immortal` for a `static let`, `@test` for a function. Written
anywhere else it would do nothing, so it is refused.

## Example

```sable
module Example

@noncopy
fn open() -> Int {
    return 1
}
```

## Fix

```sable
module Example

@noncopy
struct Handle {
    let fd: Int
}
```
