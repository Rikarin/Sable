# S3104: an async benchmark

The bencher times a body synchronously, so a benchmark cannot be `async`
yet. A test can: the harness awaits an `async` test.

## Example

```sable
module Example

import Sable.Testing

@bench
async fn waits() {
    assert(true)
}
```

## Fix

Benchmark the synchronous part, or drop `async` if the body does not await.

```sable
module Example

import Sable.Testing

@bench
fn waits() {
    assert(true)
}
```
