# S3035: `await` outside an async context

`await`, a call to an async function and `async let` may only appear inside
an async function or closure, since only those can be suspended. Writing
`await` in a plain function reports this code for the `await` and again for
the async call under it.

## Example

```sable
module Example

async fn fetch(_ key: String) -> String { return key }

fn load() -> String {
    return await fetch("a")
}
```

## Fix

Make the caller async.

```sable
module Example

async fn fetch(_ key: String) -> String { return key }

async fn load() -> String {
    return await fetch("a")
}
```
