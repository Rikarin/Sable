# S3048: `rethrows` with no throwing parameter

A `rethrows` function throws only what one of its function-typed parameters
throws, and a call to it throws only when the argument passed for that
parameter does. With no parameter of throwing function type there is nothing
for it to rethrow, so the marker means nothing and is an error. The same
applies to a function type written with `rethrows`.

## Example

```sable
module Example

fn twice(_ body: () -> Int) rethrows -> Int {
    return body() + body()
}
```

## Fix

Drop `rethrows`, or make the parameter a throwing function type if callers
mean to pass closures that throw.

```sable
module Example

fn twice(_ body: () -> Int) -> Int {
    return body() + body()
}
```
