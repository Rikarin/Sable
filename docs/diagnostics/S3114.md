# S3114: a suite the harness cannot make

A `@suite` type has one made for each of its tests, by the initialiser all of whose parameters are fixtures: types that conform to `Sable.Testing.Fixture`, which are themselves made the same way. A struct with no initialiser of its own is made of its stored properties, where they are fixtures. There is to be one such initialiser, the type is not to be generic, and nothing is to be made from itself.

## Example

```sable
module Example

import Sable.Testing

@suite
struct Orders {
    let limit: Int

    @test
    fn areLimited() {
        expect(limit > 0)
    }
}
```

## Fix

Take what the tests need from a fixture, or give it a value.

```sable
module Example

import Sable.Testing

final class Limits: Fixture {
    let most: Int = 10
}

@suite
struct Orders {
    let limits: Limits

    @test
    fn areLimited() {
        expect(limits.most > 0)
    }
}
```
