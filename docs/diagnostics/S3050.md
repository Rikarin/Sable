# S3050: an extension inside a body

A function body may declare local types, but not an extension. An extension
adds members or conformances to a type everywhere it is used, not just inside
one function, so it belongs at file scope.

## Example

```sable
module Example

struct Point {
    var x: Int
}

fn total() -> Int {
    extension Point {
        fn doubled() -> Int { return x * 2 }
    }
    return 0
}
```

## Fix

```sable
module Example

struct Point {
    var x: Int
}

extension Point {
    fn doubled() -> Int { return x * 2 }
}

fn total() -> Int {
    return Point { x: 1 }.doubled()
}
```
