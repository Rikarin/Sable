# S0003: a string that never ends

A string literal in `"` quotes must close on the line it opens on; this one
reached the end of its line (or of the file) first. A string that spans
several lines is written with `"""`.

## Example

```sable
module Example

fn greeting() -> String {
    return "hello
}
```

## Fix

```sable
module Example

fn greeting() -> String {
    return "hello"
}
```
