# S3013: iterating something that cannot be iterated

A `for ... in` loop was given a value that is not a sequence. Arrays,
dictionaries, integer ranges and sequence types can be iterated; a plain
struct cannot, and a range over a non-integer type does not enumerate.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn total(_ p: Point) -> Int {
    var sum = 0
    for n in p { sum += n }
    return sum
}
```

## Fix

```sable
module Example

struct Point { var x: Int, var y: Int }

fn total(_ p: Point) -> Int {
    var sum = 0
    let parts = [p.x, p.y]
    for n in parts { sum += n }
    return sum
}
```
