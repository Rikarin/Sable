# S3517: `#expression` where it means nothing

`#expression` is the default value of a parameter, and only that: a call that
leaves the parameter off gives it what the call's first argument is written as
and the values its parts had. So it is not the first parameter's default, nor
written anywhere else; and the parameter's type is a class that takes what it
is told, with `static fn begin()`, which makes one, and
`fn note<T>(_ text: String, _ value: T) -> T`, as Sable.Testing's
`CapturedExpression` does.

## Example

```sable
module Example

fn check(_ condition: Bool, _ written: String = #expression) {
    print(written)
}
```

## Fix

```sable
module Example

import Sable.Testing

fn check(_ condition: Bool, _ written: CapturedExpression = #expression) {
    print(written.text)
}
```
