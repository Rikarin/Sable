# S2090: a module declared by two packages

A module belongs to one package (spec/SYNTAX.md §1: the root segment of a
module's name is its package's name). When two packages in one build both
declare a module of the same name, they would merge into a single module,
each reaching the other's `internal` declarations and each able to clash with
the other's names. So it is refused: rename the module in one of them, under
its own package's name.

A single file cannot show this, since it takes two packages; the build
reports it against the second package's file.
