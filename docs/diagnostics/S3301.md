# S3301: a parameter the body never reads

The `unused_parameter` lint, a warning by default. The function never reads
one of its parameters, so every caller passes a value for nothing.

It is not reported where the signature is not the function's choice: an
`override`, a method whose name a protocol the type conforms to (or a base
class) also declares, an accessor, or `main`. Nor is a parameter that code
under an `#if` not compiled here names, or one whose type is a metatype
(`of type: T.Type`), which says what `T` is. Rename the parameter with a
leading `_` (keeping its label, if callers use one) when the signature must
stay as it is.

## Example

```sable
module Example

fn greeting(name: String, loud: Bool) -> String {
    return "hello, " + name
}
```

## Fix

Drop the parameter, or use it.

```sable
module Example

fn greeting(name: String, loud: Bool) -> String {
    return loud ? "HELLO, " + name : "hello, " + name
}
```
