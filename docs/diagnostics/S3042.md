# S3042: a method replaces a base class's method without `override`

A subclass declared a method with the same name and signature as one in a
base class. That replaces the base method for every call through the base
type, so Sable asks for `override` to say it is meant, rather than letting a
new method silently take over.

## Example

```sable
module Example

open class Shape {
    open fn area() -> F64 {
        return 0.0
    }
}

class Square: Shape {
    fn area() -> F64 {
        return 4.0
    }
}
```

## Fix

Mark it `override`, or give it a different name if it was not meant to
replace the base method.

```sable
module Example

open class Shape {
    open fn area() -> F64 {
        return 0.0
    }
}

class Square: Shape {
    override fn area() -> F64 {
        return 4.0
    }
}
```
