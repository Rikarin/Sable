# S3103: a test on an instance method

`@test` and `@bench` mark a function of a module or a `static` method: the harness has no value to call an instance method on — but a `@suite` type's, which it makes one of for each test.

## Example

```sable
module Example

import Sable.Testing

struct Counter {
    var count: Int

    @test
    fn startsAtZero() {
        assertEqual(Counter(count: 0).count, 0)
    }
}
```

## Fix

Make it `static`, move it to the module, or make the type a `@suite` that can be made (S3114).

```sable
module Example

import Sable.Testing

struct Counter {
    var count: Int

    @test
    static fn startsAtZero() {
        assertEqual(Counter(count: 0).count, 0)
    }
}
```
