# S0019: an escaped identifier that never ends

A backquoted identifier, such as `` `match` ``, lets a keyword be used as a
name. Its closing backquote must be on the same line, and this one has
none.

## Example

```sable
module Example

fn describe(`match
    : Int) -> Int {
    return 1
}
```

## Fix

```sable
module Example

fn describe(`match`: Int) -> Int {
    return `match`
}
```
