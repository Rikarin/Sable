# S3056: `unowned` on something other than a class

`unowned` marks a reference that does not keep its object alive and traps if
read after the object is gone. Only class values are references with a
count to stay out of; a struct, union or primitive is held by value, so
`unowned` means nothing for it.

## Example

```sable
module Example

struct Settings {
    var verbose: Bool
}

class Job {
    unowned var settings: Settings

    init(settings: Settings) {
        self.settings = settings
    }
}
```

## Fix

Store the value as an ordinary field (or make `Settings` a class if it is
meant to be shared).

```sable
module Example

struct Settings {
    var verbose: Bool
}

class Job {
    var settings: Settings

    init(settings: Settings) {
        self.settings = settings
    }
}
```
