# S6006: a `match` arm that earlier arms already cover

A warning: `match` tries its arms in order, and every value this arm could
match is already taken by an arm above it, so it never runs. Often it is a
`default` after arms that name every case, or a specific case placed after a
broader pattern that includes it.

## Example

```sable
module Example

enum Light { Red, Amber, Green }

fn canGo(_ light: Light) -> Bool {
    return match light {
        case .Green => true
        case .Red => false
        case .Amber => false
        default => false
    }
}
```

## Fix

```sable
module Example

enum Light { Red, Amber, Green }

fn canGo(_ light: Light) -> Bool {
    return match light {
        case .Green => true
        case .Red => false
        case .Amber => false
    }
}
```
