# S3083: a malformed array extension

An array has no name to write parameters after, so an extension of every
array of a kind declares them after the keyword:
`extension<Element> Element[>..] { … }`. Such an extension is for every
size of the array, so it writes no size or capacity (`T[]`, `T[..]`); each
parameter must appear in the array type, or nothing could say what it is;
and what it conforms the arrays to must be protocols
(`extension<Element> Element[:]: Sequence`). A named type's extension
writes its parameters after the name instead: `extension Box<T>`.

## Example

```sable
module Example

extension<T> Int[>..] {
    fn first() -> Int { return self[0] }
}
```

## Fix

Name the parameter in the array type, or leave it out when the element is
one type.

```sable
module Example

extension Int[>..] {
    fn first() -> Int { return self[0] }
}
```
