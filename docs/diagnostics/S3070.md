# S3070: `@derive` of something it cannot make

`@derive` writes a conformance from a type's fields, and it knows how to do
that for `Equatable`, `Hashable`, `Comparable` and `Debug`, for
Sable.Serialize's `Serializable` and Sable.DependencyInjection's `Injectable`,
and to say that a type is copied, `Copy`. Naming any other protocol, or writing `@derive` with no list at all,
is this error. Conform to other protocols by writing their members yourself.

## Example

```sable
module Example

@derive(Equatable, Printable)
struct Point {
    var x: Int
    var y: Int
}
```

## Fix

```sable
module Example

@derive(Equatable, Debug)
struct Point {
    var x: Int
    var y: Int
}
```
