# S3039: a static member reached through a value, or an instance member through the type

A static member belongs to the type, so it is reached through the type's
name: `Counter.zero()`. An instance member belongs to a value, so it needs
one to read it from: `counter.peek()`. Reaching either the other way is this
error; the compiler does not quietly use the value's type, or invent a value,
for you.

## Example

```sable
module Example

struct Counter {
    var n: Int

    static fn zero() -> Counter {
        return Counter { n: 0 }
    }
}

fn reset(_ counter: Counter) -> Counter {
    return counter.zero()
}
```

## Fix

Name the type instead of the value.

```sable
module Example

struct Counter {
    var n: Int

    static fn zero() -> Counter {
        return Counter { n: 0 }
    }
}

fn reset(_ counter: Counter) -> Counter {
    return Counter.zero()
}
```
