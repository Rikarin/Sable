# S3063: a signature names a type less visible than itself

A `public` (or `package`) declaration names, in its signature, a type that is
less visible than the declaration: a function's parameter, result or error
type, or a property's type. Code that can call the function, or read the
property, could then hold a value whose type it cannot name or use.

A declaration is no more visible than what holds it, so a `public` member of
an internal type is internal, and is not checked.

## Example

```sable
module Example

struct Receipt {
    var total: Int
}

public fn checkout() -> Receipt {
    return Receipt(total: 0)
}
```

## Fix

Make the type as visible as the declaration that names it, or make the
declaration less visible.

```sable
module Example

public struct Receipt {
    public var total: Int
}

public fn checkout() -> Receipt {
    return Receipt(total: 0)
}
```
