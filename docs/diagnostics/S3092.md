# S3092: an attribute there is not

An attribute is one spec/SYNTAX.md §22 lists — `@inline`, `@noncopy`,
`@deprecated`, `@available`, `@frozen`, `@derive`, `@test` and the rest —
or one the compiler uses itself (`@allow`, `@warn`). On a field of a struct
that derives `Validatable`, it may be a rule of Sable.Validation's
`FieldRules`, or of an extension of it, that fits the field's type. A name that is none of
them is most likely misspelt, and an attribute that silently did nothing
would be worse than an error.

## Example

```sable
module Example

@inlined(always)
fn twice(_ n: Int) -> Int {
    return n * 2
}
```

## Fix

```sable
module Example

@inline(always)
fn twice(_ n: Int) -> Int {
    return n * 2
}
```
