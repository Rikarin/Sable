# S3481: `yield` in a `defer`

A `defer` body runs as its scope is left: in a generator, that may be when
the body finishes, or when the iterator running it is dropped before it does
(SYNTAX.md §5, "Generators"). Nothing is asking for an element then, so a
`defer` cannot give one.

## Example

```sable
module Example

fn framed(_ items: Int[]) -> some Sequence<Int> {
    defer {
        yield -1
    }
    for item in items {
        yield item
    }
}
```

## Fix

Yield the last element where the body ends, and keep the `defer` for what
must happen however it ends:

```sable
module Example

fn framed(_ items: Int[]) -> some Sequence<Int> {
    for item in items {
        yield item
    }
    yield -1
}
```
