# S3663: a format spec for a type that does not write itself

A value whose type conforms to `Formattable` is given its hole's format spec,
and writes itself as the spec asks. Any other value is written as an
interpolation always writes it — an enum as its case's name, a `Debug` value
as it describes itself, anything else as `Reflect.describe` does — and that
text can only be padded: a fill, an alignment and a width apply to it, and
`?`. A kind, a precision, a sign, `#`, `0` or a separator would be ignored,
so it is refused. A type parameter is held to what its constraints promise.

## Example

```sable
module Example

struct Celsius {
    var degrees: F64
}

fn show(_ t: Celsius) -> String {
    return "\(t:.1)"
}
```

## Fix

Make the type `Formattable`, so that it decides what the spec means — or
format the field that is a number.

```sable
module Example

struct Celsius: Formattable {
    var degrees: F64

    fn format(_ spec: FormatSpec) -> String {
        return self.degrees.format(spec) + " °C"
    }
}

fn show(_ t: Celsius) -> String {
    return "\(t:.1)"
}
```
