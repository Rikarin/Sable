# S0029: an `#error` directive

The program reached an `#error` directive, which reports its message as an
error wherever it is compiled. It is usually placed in a conditional
block, to stop a build that targets something the code does not support.
An `#error` in a block that is left out reports nothing.

## Example

```sable
module Example

#error "not finished"

fn one() -> Int {
    return 1
}
```

## Fix

Remove the directive once its reason is gone, or put it in the conditional
block it is meant for.

```sable
module Example

#if os(plan9)
#error "not supported on Plan 9"
#endif

fn one() -> Int {
    return 1
}
```
