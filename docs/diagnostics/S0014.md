# S0014: an integer literal too large for 128 bits

Integer literals are read as unsigned numbers of up to 128 bits, so no
literal can exceed 340282366920938463463374607431768211455 (`U128`'s
largest value). Whether a smaller literal fits the type it is used as is
checked afterwards, against that type: one past 64 bits suits only `I128`,
`U128` or a floating-point type.

## Example

```sable
module Example

fn big() -> F64 {
    return 1000000000000000000000000000000000000000
}
```

## Fix

A floating-point literal can hold a value this large, approximately.

```sable
module Example

fn big() -> F64 {
    return 1e39
}
```
