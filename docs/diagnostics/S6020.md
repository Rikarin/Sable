# S6020: `fallthrough` with no case to go on to

`fallthrough` ends a `switch` case by going on into the case written after
it. It is only allowed in a `switch` case, and not in the last one, which has
no case after it. A closure or local function written in a case is a body of
its own, and cannot fall through out of it.

## Example

```sable
module Example

fn describe(_ code: Int) {
    switch code {
        case 200: print("ok")
        default:
            print("something else")
            fallthrough
    }
}
```

## Fix

Let the last case end on its own, or move the code it should go on to into a
case after it.

```sable
module Example

fn describe(_ code: Int) {
    switch code {
        case 200: print("ok")
        default: print("something else")
    }
}
```
