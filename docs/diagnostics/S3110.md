# S3110: a benchmark that throws

A test may be declared `throws`, and fails if it throws; a benchmark cannot, since there is no test for its error to fail. Handle the error inside the benchmark.

## Example

```sable
module Example

import Sable.Testing

union ParseError {
    Empty
}

fn parse(_ text: String) throws(ParseError) -> Int {
    if text.isEmpty {
        throw .Empty
    }
    return text.count
}

@bench
fn parsing() throws(ParseError) {
    let n = try parse("12345")
}
```

## Fix

Handle the error in the body, here by turning it into an optional.

```sable
module Example

import Sable.Testing

union ParseError {
    Empty
}

fn parse(_ text: String) throws(ParseError) -> Int {
    if text.isEmpty {
        throw .Empty
    }
    return text.count
}

@bench
fn parsing() {
    let n = try? parse("12345")
}
```
