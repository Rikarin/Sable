# S3019: `self` outside a type

`self`, `Self` and `super` refer to the enclosing type, or to the instance a
method was called on. A free function belongs to no type, so none of them
mean anything there. A static member belongs to the type but is called on no
value, so it has no `self`, and the members of a value are not its to name alone.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn horizontal() -> Int {
    return self.x
}
```

## Fix

Make the function a method, or pass the value in as a parameter.

```sable
module Example

struct Point {
    var x: Int
    var y: Int

    fn horizontal() -> Int {
        return self.x
    }
}
```
