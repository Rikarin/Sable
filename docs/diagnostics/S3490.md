# S3490: a type declared PlainData is not its bytes alone

A type that declares `: PlainData` (or a protocol that refines it) promises
that a value is its bytes and nothing else, so that a slice of it may be
seen as a slice of another plain type, or of bytes, with nothing copied
(`reinterpreted(as:)`, `bytes`). The promise is checked where it is made:
every stored field must be PlainData — an integer, a float, a struct of
them, an inline array `T[k]` of one — and the fields must be laid out with
no padding between them or after the last, with no deinit, and the type
neither `@noncopy` nor `@inline_layout`.

A Bool and a Char are not PlainData, as not every pattern of bits is one;
nor an enum, a union or an optional, whose tag is not; nor a class, an
array with a buffer, a closure or a reference, which hold an address; nor a
tuple, whose layout is not promised.

## Example

```sable
module Example

struct Sample: PlainData {
    var level: U8
    var time: U32
}
```

## Fix

Order the fields so that none needs padding, or make the padding a field
of its own.

```sable
module Example

struct Sample: PlainData {
    var time: U32
    var level: U8
    var reserved: U8
    var spare: U16
}
```
