# S3202: an `out` parameter is not assigned on every path

An `out` parameter is how a function hands back a second result: the
caller's variable comes in with no value the callee may read, and is read by
the caller afterwards. So every way the function returns — each `return`,
and falling off the end — must assign it first. (A `throw` need not: the
caller does not read it then.)

## Example

```sable
module Example

fn half(_ n: Int, out value: Int) -> Bool {
    if n > 0 {
        value = n / 2
        return true
    }
    return false
}

@main
fn main() {
    var v = 0
    if half(10, out v) {
        print(v)
    }
}
```

## Fix

Assign it on the path that missed it.

```sable
module Example

fn half(_ n: Int, out value: Int) -> Bool {
    if n > 0 {
        value = n / 2
        return true
    }
    value = 0
    return false
}

@main
fn main() {
    var v = 0
    if half(10, out v) {
        print(v)
    }
}
```
