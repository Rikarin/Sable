# S3303: a `var` that could be a `let`

The `var_never_mutated` lint, a warning by default. The variable is given a
value where it is declared and never changed afterwards: nothing assigns to
it or into it, calls a mutating method on it, or passes it as `&` or `out`.
A `let` says so to the reader, and lets the compiler hold you to it.

A `var` declared without a value is not reported, since it is assigned later.

## Example

```sable
module Example

fn describe(_ n: Int) -> String {
    var text = "n is \(n)"
    return text
}
```

## Fix

```sable
module Example

fn describe(_ n: Int) -> String {
    let text = "n is \(n)"
    return text
}
```
