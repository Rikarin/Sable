# S1001: a token that was expected but not found

The parser needed one particular token here, such as a closing `)` or `}`,
a `:` or an `=`, and found something else. The message names both. It is
reported where the missing token should have been, which for an unclosed
bracket is often the start of the next line.

## Example

```sable
module Example

fn sum() -> Int {
    return (1 + 2
}
```

## Fix

```sable
module Example

fn sum() -> Int {
    return (1 + 2)
}
```
