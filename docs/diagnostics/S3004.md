# S3004: a value of the wrong type

A value was used where a different type is expected: assigned to an annotated
binding, returned from a function, passed as an argument, or stored in a
field. Sable converts implicitly only where nothing can be lost or
misread — an `Int` never silently becomes a `String`, nor an `F64` an `Int`.

Two types can print alike and still differ. Each function returning
`some Shape` returns a type of its own, so the result of one cannot be
stored where the other's is held; the message names the function (or
variable, or type arguments) that chose each. Use `any Shape` to hold
either.

## Example

```sable
module Example

fn describe() -> String {
    let count: Int = "three"
    return "\(count)"
}
```

## Fix

Give the binding a value of its type, or convert explicitly.

```sable
module Example

fn describe() -> String {
    let count: Int = 3
    return "\(count)"
}
```
