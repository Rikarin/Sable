# S3162: a Type that cannot be opened for this call

A `Type` given for a generic function's `T.Type` parameter opens it: `T`
is the type the value holds when the program runs, which the compiler does
not know. The function runs compiled once for every type, given that type's
metadata, and the conformance registry is asked for its witness tables of
the protocols `T` must conform to.

So the call can open the `Type` only when that is all `T` asks for:

- `T` may be constrained only to protocols that are not generic: a class
  bound (`T: Animal`) or an instance of a generic protocol
  (`T: Producer<Int>`) is not something the registry can be asked about;
- no other parameter may be of `T` (or of a type made of it, `T[]`): no
  value of a type known only at run time can be written to give it;
- the function's `where` clause may not make `T` the same as another type.

## Example

```sable
module Example

protocol Shape {
    fn area() -> Int
}

fn total<T: Shape>(_ type: T.Type, of shapes: T[]) -> Int {
    var sum = 0
    for shape in shapes {
        sum = sum + shape.area()
    }

    return sum
}

fn measure(_ t: Type) -> Int {
    return total(t, of: [])
}
```

## Fix

Give the function only the type, and let it make the values it needs from
its protocols' requirements; or take existentials instead.

```sable
module Example

protocol Shape {
    fn area() -> Int
}

fn total(of shapes: (any Shape)[]) -> Int {
    var sum = 0
    for shape in shapes {
        sum = sum + shape.area()
    }

    return sum
}

fn measure(_ t: Type) -> Int {
    return total(of: [])
}
```
