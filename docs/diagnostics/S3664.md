# S3664: a closure declared `rethrows`

`rethrows` says a function throws only when a closure it is given throws, so
its callers know when a call can fail. A closure is not called that way: its
type says what it throws, `throws(E)`, or it says nothing and its body decides.

## Example

```sable
module Example

union ParseError: Error { Bad }

fn count(_ text: String) throws(ParseError) -> Int {
    let parse = { (s: String) rethrows -> Int in
        return s.count
    }
    return parse(text)
}
```

## Fix

Write `throws(E)` for the error the closure throws, or leave it out and let
the body say.

```sable
module Example

union ParseError: Error { Bad }

fn count(_ text: String) throws(ParseError) -> Int {
    let parse = { (s: String) throws(ParseError) -> Int in
        if s.isEmpty {
            throw ParseError.Bad
        }
        return s.count
    }
    return try parse(text)
}
```
