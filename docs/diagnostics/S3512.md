# S3512: a function `@polymorphic` cannot be

A generic function is compiled once for each set of types it is called
with. `@polymorphic` compiles it once instead: each type parameter stands
for `any` of its constraints, so a value of it is passed in a box, with the
witness table of its type's conformances, and the result is taken back out
of its box as the type the call gives it.

That needs a function whose values can be passed that way:

- it has type parameters of its own, and is not inside a generic type or
  another function;
- each type parameter is constrained to protocols alone, none with an
  associated type or a requirement that mentions `Self` (`Equatable`'s `==`),
  which a box of an unknown type cannot meet;
- each parameter, and the result, is a type parameter itself or mentions
  none — a `T[>..]` would need each element boxed — and no parameter of a
  type parameter is `inout`.

## Example

```sable
module Example

protocol Shape {
    fn area() -> Int
}

@polymorphic
fn total<S: Shape>(_ shapes: S[>..]) -> Int {
    var sum = 0
    for shape in shapes {
        sum += shape.area()
    }
    return sum
}
```

## Fix

```sable
module Example

protocol Shape {
    fn area() -> Int
}

@polymorphic
fn area<S: Shape>(_ shape: S) -> Int {
    return shape.area()
}
```
