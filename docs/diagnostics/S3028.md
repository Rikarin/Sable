# S3028: a field left unset

A struct literal such as `Point { x: 1 }` must give every stored field that
has no default value; a value with a field never set would hold whatever
bytes happened to be there. An initialiser must likewise assign each such
field on every path through it that finishes the value — falling off the
end or returning; a path that throws builds nothing.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn origin() -> Point {
    return Point { x: 0 }
}
```

## Fix

Give the missing field a value, or a default in the struct. In an
initialiser, assign it on every path.

```sable
module Example

struct Point { var x: Int, var y: Int }

fn origin() -> Point {
    return Point { x: 0, y: 0 }
}
```
