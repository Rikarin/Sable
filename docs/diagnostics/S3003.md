# S3003: a variable-size value where a fixed size is needed

A union declared variable-size (`union Name..`) takes only as many bytes as
its current case needs, so its values do not all have one size. An `any P`
existential box holds its value in a fixed amount of space, so a
variable-size value cannot be converted to one.

## Example

```sable
module Example

protocol Named { fn name() -> String }

union Shape..: Named {
    Dot(x: Int)
    Rect(x: Int, y: Int, w: Int, h: Int)

    fn name() -> String { return "shape" }
}

fn boxed(_ s: Shape) -> any Named {
    return s
}
```

## Fix

Declare the union without `..` so every value has the same size, or keep the
concrete type (or a `some Named` generic) instead of boxing it.

```sable
module Example

protocol Named { fn name() -> String }

union Shape: Named {
    Dot(x: Int)
    Rect(x: Int, y: Int, w: Int, h: Int)

    fn name() -> String { return "shape" }
}

fn boxed(_ s: Shape) -> any Named {
    return s
}
```
