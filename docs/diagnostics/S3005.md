# S3005: the type cannot be inferred

The compiler had nothing to work out a type from. An empty array literal `[]`
says nothing about its element type, and a `let` or `var` with neither a
type annotation nor an initialiser has no type at all. The same code covers
a few related spots, such as a `catch` fallback whose value has to match a
type the compiler cannot see.

## Example

```sable
module Example

fn count() -> Int {
    let items = []
    return items.count
}
```

## Fix

Annotate the binding so the literal has a type to take.

```sable
module Example

fn count() -> Int {
    let items: Int[] = []
    return items.count
}
```
