# S3390: a local that hides one from a block around it

The `shadowed_local` lint, a warning by default. A `let` or `var` inside an
inner block — an `if`, a loop, a closure — has the name of a local declared
in a block around it, so inside the inner block the name means the new
local and the outer one cannot be reached. That is legal, but it is easy to
read, or change, the wrong one.

Declaring a name again in the same block (`let line = line.trimmed()`) is
a deliberate rebinding, and unwrapping in place (`if let value = value`) is
the idiom; neither is reported. A local that hides a parameter is S3304.

## Example

```sable
module Example

fn total(_ prices: Int[]) -> Int {
    let sum = 0
    for price in prices {
        let sum = sum + price
        print(sum)
    }
    return sum
}
```

## Fix

Give the inner value its own name; here it was meant to change the outer one.

```sable
module Example

fn total(_ prices: Int[]) -> Int {
    var sum = 0
    for price in prices {
        sum += price
    }
    return sum
}
```
