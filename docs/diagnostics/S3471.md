# S3471: `unsafe` on something that is not a function

`unsafe` modifies a function or an initialiser alone: `unsafe fn`, `unsafe
static fn`, an `unsafe mutating fn`, `unsafe init`. What its caller vouches for
is a call, so a property or a type cannot be `unsafe`. (The `unsafe` of
`unowned(unsafe)`, a reference that is not checked, is another thing.)

## Example

```sable
module Example

unsafe static let table = 1
```

## Fix

Remove `unsafe`. Where reading or making the thing is safe only on a promise,
offer an `unsafe fn` that does it.

```sable
module Example

static let table = 1
```
