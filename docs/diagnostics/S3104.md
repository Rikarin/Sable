# S3104: a fuzz target's signature

A `@fuzz` function takes exactly one `U8[:]`, the bytes the fuzzer chose for this run; or one to four values, which `sable fuzz` makes of those bytes, each of a type that conforms to `Sable.Testing.Arbitrary`. Its parameters are plain ones (not `inout`, variadic or `@autoclosure`), and it is not `async`: `sable fuzz` calls it from C once an input, and waits for nothing. It fails by trapping (a failed assertion, an index out of range, a `fatalError`) or by throwing; what it returns is nothing.

## Example

```sable
module Example

import Sable.Testing

struct Order {
    var id: Int
    var lines: String[>..]
}

@fuzz
fn totals(_ order: Order) {
    assert(order.lines.count >= 0)
}
```

## Fix

Derive `Arbitrary` for the type, and for the types of its fields; or take the bytes, and make of them what the code under test reads.

```sable
module Example

import Sable.Testing
import Sable.Text

@derive(Arbitrary)
struct Order {
    var id: Int
    var lines: String[>..]
}

@fuzz
fn totals(_ order: Order) {
    assert(order.lines.count >= 0)
}

@fuzz
fn parses(_ data: U8[:]) {
    let text = String.fromUtf8Lossy(data)
    assert(text.count >= 0)
}
```
