# S3029: an extension with a stored property

An extension may add methods, computed properties, subscripts, operators,
static members, nested types and conformances, but not stored properties. A
type's layout is fixed where it is declared; an extension elsewhere cannot
make its values larger.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

extension Point {
    var z: Int
}
```

## Fix

Make it a computed property, or add the field to the type itself.

```sable
module Example

struct Point { var x: Int, var y: Int }

extension Point {
    var sum: Int { get => x + y }
}
```
