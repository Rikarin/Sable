# S0013: an underscore at the end of a number

`_` separates groups of digits in a numeric literal, so it may only stand
between digits, and here the literal ends with one.

## Example

```sable
module Example

fn million() -> Int {
    return 1_000_000_
}
```

## Fix

```sable
module Example

fn million() -> Int {
    return 1_000_000
}
```
