# S3232: a generator reported an error

A source generator (docs/08) called `output.error(message)` for this
declaration. The message is the generator's own and starts with the
generator's name. It is reported at the attribute that started the run, and
the build fails.

A generator does this when it cannot handle the declaration as written, for
example `@json` on a union that it cannot serialise, or an argument it does
not understand. The message should say what to change. If it does not, look
at the generator in the `generators/` directory of the package that declares
it.
