# S6005: code that can never run

A warning: the statement comes after something that always leaves the
block (a `return`, `throw`, `break` or `continue`, or a call that never
returns), so no path reaches it. It is usually left over from an edit, or a
sign that the jump above it was meant to be conditional.

## Example

```sable
module Example

fn total(_ values: Int[]) -> Int {
    var sum = 0
    for v in values {
        sum = sum + v
    }
    return sum
    print("done")
}
```

## Fix

Remove the dead code, or move it before the jump.

```sable
module Example

fn total(_ values: Int[]) -> Int {
    var sum = 0
    for v in values {
        sum = sum + v
    }
    print("done")
    return sum
}
```
