# S3032: a throwing call without `try`

A call to a function that can throw must be marked with `try` (to pass the
error on), `try?` (to turn it into an optional) or `try ... catch` (to supply
a fallback). The mark keeps every point where control can leave early
visible in the source.

## Example

```sable
module Example

union ParseError { Empty }

fn parse(_ s: String) throws(ParseError) -> Int { return 0 }

fn read() throws(ParseError) -> Int {
    return parse("1")
}
```

## Fix

```sable
module Example

union ParseError { Empty }

fn parse(_ s: String) throws(ParseError) -> Int { return 0 }

fn read() throws(ParseError) -> Int {
    return try parse("1")
}
```
