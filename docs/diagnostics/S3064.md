# S3064: a constant's arithmetic overflows

A `const` is worked out by the compiler, so integer arithmetic in its
initialiser is done as the program is compiled. A result its type cannot
hold, or a division by zero, would otherwise trap the moment the program
starts; the compiler reports it where it is written instead.

## Example

```sable
module Example

const Limit: Int = 9223372036854775807 + 1

@main
fn main() {
    print(Limit)
}
```

## Fix

Keep the arithmetic within the constant's type, or give the constant a type
wide enough for the result.

```sable
module Example

const Limit: Int = 9223372036854775806 + 1

@main
fn main() {
    print(Limit)
}
```
