# S0002: a block comment that never ends

A `/*` comment runs until its matching `*/`, and the end of the file came
first. Block comments nest, so every `/*` inside one needs its own `*/` as
well. Everything after the opening `/*` was read as comment, which is why
nothing else in the file is reported.

## Example

```sable
module Example

/* Adds two numbers.
fn add(a: Int, b: Int) -> Int {
    return a + b
}
```

## Fix

```sable
module Example

/* Adds two numbers. */
fn add(a: Int, b: Int) -> Int {
    return a + b
}
```
