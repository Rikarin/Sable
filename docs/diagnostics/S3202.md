# S3202: compileError reached

`compileError("message")` stops the compile with its message, where the call
is, when a `comptime` block or the computing of a `const` reaches it
(SYNTAX.md §21). It is how a program says, at compile time, that it cannot be
built as it stands: on this platform, with these constants.

## Example

```sable
module Example

const Workers: Int = 0

comptime {
    if Workers < 1 {
        compileError("Workers must be at least 1")
    }
}
```

## Fix

```sable
module Example

const Workers: Int = 4

comptime {
    if Workers < 1 {
        compileError("Workers must be at least 1")
    }
}
```
