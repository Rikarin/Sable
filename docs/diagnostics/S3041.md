# S3041: a mutating method called on something that cannot change

A `mutating` method changes the value it is called on, so the receiver must
be something that can be changed: a `var`, an `inout` parameter, or a field
of one. A `let` binding and an ordinary parameter are read-only, so calling a
mutating method through them is an error rather than a silent change to a
copy.

## Example

```sable
module Example

struct Counter {
    var n: Int

    mutating fn bump() {
        n = n + 1
    }
}

fn count() -> Int {
    let counter = Counter { n: 0 }
    counter.bump()
    return counter.n
}
```

## Fix

Declare the binding with `var` (or take the parameter `inout`).

```sable
module Example

struct Counter {
    var n: Int

    mutating fn bump() {
        n = n + 1
    }
}

fn count() -> Int {
    var counter = Counter { n: 0 }
    counter.bump()
    return counter.n
}
```
