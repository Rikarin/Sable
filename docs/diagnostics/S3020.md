# S3020: a name that cannot be used as a value

The name refers to something that exists but has no value to give: a
protocol, which cannot be instantiated; a type that declares no initialiser,
called as if it had one; or a member that is not a value.

## Example

```sable
module Example

protocol Shape { fn area() -> F64 }

fn make() -> F64 {
    let s = Shape()
    return s.area()
}
```

## Fix

Construct a concrete type that conforms to the protocol.

```sable
module Example

protocol Shape { fn area() -> F64 }

struct Square: Shape {
    var side: F64

    fn area() -> F64 { return side * side }
}

fn make() -> F64 {
    let s = Square { side: 2.0 }
    return s.area()
}
```
