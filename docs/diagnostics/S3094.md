# S3094: an attribute with the wrong arguments

Some attributes take arguments, and read them: `@inline(always)` or
`@inline(never)`; `@deprecated` with at most a message, as a string;
`@available` with the platforms it is for, each alone or with a version as
a string; `@align` with a power of two. Others, such as `@frozen` and
`@discardable`, take none.

## Example

```sable
module Example

@inline(sometimes)
fn twice(_ n: Int) -> Int {
    return n * 2
}
```

## Fix

```sable
module Example

@inline(never)
fn twice(_ n: Int) -> Int {
    return n * 2
}
```
