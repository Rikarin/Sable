# S7004: an inline array too large to hold inline

`T[k]` and `T[..k]` hold their elements where the array is (docs/02 §2.5,
"The array family"): in a local, which is the frame's, in a struct's field, in
a union's payload. Copying one copies every element, and a value of one is
held on the stack while it is worked on — and a thread's stack may be as small
as 256 KiB. So an inline array takes at most 64 KiB: `U8[65536]` is the largest
array of bytes, `Int[8192]` of Ints. A larger one is this error, at the code
that needs it.

The heap's kinds hold any number of elements: `T[]`, fixed at construction,
or `T[>..]`, which grows.

## Example

```sable
module Example

fn main() {
    var table: Int[..10000] = []
    table.append(1)
}
```

## Fix

```sable
module Example

fn main() {
    var table: Int[>..] = []
    table.append(1)
}
```
