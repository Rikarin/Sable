# S0009: a malformed Unicode escape

A Unicode escape is written `\u{...}`, with between one and six hexadecimal
digits inside the braces. The forms `\u0041` and `\uD83D` from other
languages are not accepted, and neither are braces that hold no digits,
something other than hex digits, or no closing `}`.

## Example

```sable
module Example

fn letter() -> String {
    return "\u0041"
}
```

## Fix

```sable
module Example

fn letter() -> String {
    return "\u{41}"
}
```
