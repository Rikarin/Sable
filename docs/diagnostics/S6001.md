# S6001: a case the union or enum does not have

A pattern such as `.Triangle` names a case of the type being matched, and that
type declares no case of that name. Check the spelling, and that the value
being matched has the type you expect.

## Example

```sable
module Example

enum Shape { Circle, Square }

fn sides(_ s: Shape) -> Int {
    return match s {
        case .Circle => 0
        case .Sqaure => 4
    }
}
```

## Fix

```sable
module Example

enum Shape { Circle, Square }

fn sides(_ s: Shape) -> Int {
    return match s {
        case .Circle => 0
        case .Square => 4
    }
}
```
