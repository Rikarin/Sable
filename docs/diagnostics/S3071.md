# S3071: `@derive` on a type it does not fit

`@derive` is for structs and unions, whose values are their fields, and for
enums, whose values are their cases. A class or actor object has identity,
so equality and hashing made from its fields would call two distinct objects
equal; write `==` and `hash()` for it instead. A `@flags` enum's values are
sets of its cases, compared as the integers they are, so it derives
nothing. The same code is reported when the type already declares the
member `@derive` would make (an `==` of its own, say), since there would
then be two.

## Example

```sable
module Example

@derive(Equatable)
class Account {
    var id: Int

    init(id: Int) {
        self.id = id
    }
}
```

## Fix

Make it a struct if its values are just their fields, or write the
conformance by hand.

```sable
module Example

@derive(Equatable)
struct Account {
    var id: Int
}
```
