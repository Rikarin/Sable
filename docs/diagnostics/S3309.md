# S3309: `let _ =` declares nothing

The `let_discard` lint, a warning by default. `let _ = f()` calls `f` and
drops what it gives, and the `let` declares nothing. `_ = f()` says the same.
`sable fix` rewrites it.

It is not reported for `async let _`, which starts a child task, for `using`,
or where a type is written (`let _: I8 = 5`), which says what the value is
made as.

## Example

```sable
module Example

fn twice(_ n: Int) -> Int {
    return n * 2
}

fn run() {
    let _ = twice(4)
}
```

## Fix

```sable
module Example

fn twice(_ n: Int) -> Int {
    return n * 2
}

fn run() {
    _ = twice(4)
}
```
