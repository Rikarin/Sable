# S3081: `@builtin` or `@intrinsic` outside the standard library

`@builtin("name")` declares a function or property whose body the compiler
supplies. A builtin trusts its operands: it does none of the checks the
language otherwise makes. So only the standard library, whose builtins are
written together with the compiler, may declare one: `Sable.Core` and the
other modules named `Sable.*` (`Sable.Math` declares F64's `sin` to be
libm's). Everywhere else, write the body in Sable, calling the standard
library.

`@intrinsic` is narrower still: a declaration of `Sable.Core` whose body
the compiler writes for each type it is used with (`Platform.os`, the
reflection of a type). Only `Sable.Core` may declare one.

## Example

```sable
module Example

@builtin("string_trimmed")
fn trimmed(_ text: String) -> String
```

## Fix

```sable
module Example

fn trimmed(_ text: String) -> String {
    return text.trimmed()
}
```
