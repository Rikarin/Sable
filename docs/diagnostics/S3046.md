# S3046: a conformance declared outside both modules involved

`extension T: P` may be written only in the module that declares `T` or the
module that declares `P`. If a third module could declare it, two libraries
could each declare the same conformance differently, and a program that used
both would have no single answer to how `T` is a `P`. With the rule, every
conformance has one home.

## Example

```sable
module Example

extension Reflect: Hashable {
    public operator == (lhs: Reflect, rhs: Reflect) -> Bool { return true }
    public fn hash() -> Int { return 0 }
}
```

## Fix

Wrap the type in a struct of your own and declare the conformance on that.

```sable
module Example

struct Token: Hashable {
    var id: Int

    operator == (lhs: Token, rhs: Token) -> Bool { return lhs.id == rhs.id }
    fn hash() -> Int { return id }
}
```
