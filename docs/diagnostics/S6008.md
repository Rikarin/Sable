# S6008: a variable read before it is assigned

A variable may be declared without a value (`var n: Int`), but then every
path to a read of it must assign it first. Sable does not fill in a default
such as zero, so a read on a path where nothing assigned it is an error.

## Example

```sable
module Example

fn pick(_ flag: Bool) -> Int {
    var n: Int
    if flag {
        n = 1
    }
    return n
}
```

## Fix

Assign it on every path, or give it a value where it is declared.

```sable
module Example

fn pick(_ flag: Bool) -> Int {
    var n: Int
    if flag {
        n = 1
    } else {
        n = 0
    }
    return n
}
```
