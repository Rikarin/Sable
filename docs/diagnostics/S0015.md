# S0015: a malformed floating-point literal

The literal starts like a number but does not finish as one: an exponent
marker `e` with no digits after it, a malformed binary exponent in a
hexadecimal float, or letters after the number. An exponent needs digits
after the `e` and its optional sign. Sable has no literal suffixes such as
`f` or `u8`; to give a literal a particular type, annotate the binding or
convert with `as`.

## Example

```sable
module Example

fn thousand() -> F64 {
    return 1.0e
}
```

## Fix

```sable
module Example

fn thousand() -> F64 {
    return 1.0e3
}
```
