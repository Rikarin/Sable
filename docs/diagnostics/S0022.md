# S0022: a digit that does not belong to the number's base

A binary literal (`0b`) takes only `0` and `1`, an octal one (`0o`) only `0`
to `7`, and a hexadecimal one (`0x`) `0` to `9` and `a` to `f`. This literal
has a digit its base does not have.

## Example

```sable
module Example

fn flags() -> Int {
    return 0b1021
}
```

## Fix

```sable
module Example

fn flags() -> Int {
    return 0b1011
}
```
