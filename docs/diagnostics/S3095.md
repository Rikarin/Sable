# S3095: a deprecated declaration is used

A warning. The declaration is marked `@deprecated`, usually with a message
saying what to use instead; the use still compiles. A use inside the
deprecated declaration itself, or inside another deprecated one, is not
reported.

## Example

```sable
module Example

@deprecated("use 'area'")
fn size(_ side: Int) -> Int {
    return side * side
}

fn area(_ side: Int) -> Int {
    return side * side
}

fn floor() -> Int {
    return size(4)
}
```

## Fix

```sable
module Example

@deprecated("use 'area'")
fn size(_ side: Int) -> Int {
    return side * side
}

fn area(_ side: Int) -> Int {
    return side * side
}

fn floor() -> Int {
    return area(4)
}
```
