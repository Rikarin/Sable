# S6000: a pattern that cannot match the value's type

A pattern is checked against the type of the value it is matched with. A
literal pattern must have that type, a tuple pattern must have as many
elements as the tuple, and a range pattern needs a type whose values are
ordered. A pattern of some other shape could never match, so it is an error
rather than an arm that is silently dead.

## Example

```sable
module Example

fn describe(_ pair: (Int, String)) -> Int {
    return match pair {
        case (let n, let s, let t) => n
    }
}
```

## Fix

```sable
module Example

fn describe(_ pair: (Int, String)) -> Int {
    return match pair {
        case (let n, let s) => n + s.count
    }
}
```
