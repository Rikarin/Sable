# S3233: a generator reported a warning

A source generator (docs/08) called `output.warning(message)` for this
declaration. The message is the generator's own and starts with the
generator's name. It is reported at the attribute that started the run. The
build goes on, and what the generator wrote is compiled.

A generator warns about something it can handle but that is probably a
mistake, such as a field it skips or an argument with no effect.
