# S0028: a malformed `#if` condition

The condition after `#if` or `#elseif` is missing or is not one the
directive understands. It is evaluated before anything else in the program
exists, so it may use only identifiers, `true`, `false`, the tests `os(...)`,
`arch(...)` and `feature(...)`, the operators `!`, `&&` and `||`, and
parentheses; not comparisons, numbers or calls to functions. A malformed
condition counts as false, so its block is left out.

## Example

```sable
module Example

#if VERSION >= 2
fn version() -> Int {
    return 2
}
#endif
```

## Fix

```sable
module Example

#if VERSION_2
fn version() -> Int {
    return 2
}
#endif
```
