# S7003: a generic function that needs endless copies of itself

Sable compiles a generic function once for each set of type arguments it is
used with. A generic function that calls itself — directly, or through other
functions — with a type argument built from its own, such as `(T, T)`, `T[]`
or `Box<T>`, therefore needs a copy for a larger type each time: the copy for
`Int` needs one for `(Int, Int)`, which needs one for
`((Int, Int), (Int, Int))`, and so on without end. How many times the calls
actually run does not matter; the copies are made before the program runs.
This is called polymorphic recursion.

The compiler stops when it sees a copy ask for a larger copy of the same
function, and points at the call that does.

## Example

```sable
module Example

fn deep<T>(_ x: T, _ n: Int) -> Int {
    if n == 0 { return 0 }
    return deep((x, x), n - 1)
}

fn main() { print(deep(1, 3)) }
```

## Fix

Keep what grows in a value rather than in a type, so the recursion calls the
same copy of the function each time.

```sable
module Example

fn deep<T>(_ x: T, _ copies: Int, _ n: Int) -> Int {
    if n == 0 { return copies }
    return deep(x, copies * 2, n - 1)
}

fn main() { print(deep(1, 1, 3)) }
```
