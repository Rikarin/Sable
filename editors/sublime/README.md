# Sable for Sublime Text

- `Sable.tmLanguage`: the VS Code grammar, as the property list Sublime reads,
  generated by `node generate.js` (run it after changing
  `editors/vscode/syntaxes/sable.tmLanguage.json`; `editors/test` fails while
  they differ).
- `Comments.tmPreferences`: `//` and `/* */` for the comment commands.
- `Sable.sublime-settings`: four spaces, as `sable fmt` writes.

## Install

Copy or link this directory into Sublime's `Packages` directory as `Sable`
(**Preferences → Browse Packages…**):

```sh
ln -s /path/to/sable/editors/sublime "$HOME/Library/Application Support/Sublime Text/Packages/Sable"   # macOS
ln -s /path/to/sable/editors/sublime ~/.config/sublime-text/Packages/Sable                            # Linux
```

## The language server

With the [LSP](https://packagecontrol.io/packages/LSP) package, add a client in
**Preferences → Package Settings → LSP → Settings**:

```json
{
  "clients": {
    "sable": {
      "enabled": true,
      "command": ["sable", "lsp"],
      "selector": "source.sable",
      "initializationOptions": {
        "inlayHints": { "enable": true },
        "lints": { "enable": true }
      }
    }
  }
}
```

`"show_inlay_hints": true` in the LSP settings shows the server's inlay hints;
**LSP: Format File** formats with `sable fmt`'s formatter.
