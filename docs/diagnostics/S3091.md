# S3091: a half-open range with no upper bound

`a..<b` holds the values from `a` up to, but not including, `b`. Written
without `b`, it stops before an end it does not name, so there is no such
range. The values from `a` on, with no end, are `a...`; a range that stops
somewhere needs the bound written.

## Example

```sable
module Example

fn from(_ start: Int) -> Bool {
    let rest = (start..<)
    return true
}
```

## Fix

```sable
module Example

fn from(_ start: Int) -> Bool {
    let rest = start...
    return rest.contains(start)
}
```
