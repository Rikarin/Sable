# S2005: an alias defined in terms of itself

A type alias stands for another type, so following the aliases must end
at a type that is not an alias. Here it leads back to where it started,
directly or through other aliases.

## Example

```sable
module Example

alias Meters = Distance
alias Distance = Meters

fn zero() -> Meters {
    return 0
}
```

## Fix

```sable
module Example

alias Meters = Distance
alias Distance = Int

fn zero() -> Meters {
    return 0
}
```
