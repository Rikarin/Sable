# S3015: array elements of different types

An array literal holds one element type, taken from the context or from its
first element. An element that does not convert to that type is reported
here. For a mixed collection, annotate the array with an element type that
covers every element, such as a structural union.

## Example

```sable
module Example

fn values() -> Int {
    let xs = [1, "two"]
    return xs.count
}
```

## Fix

```sable
module Example

fn values() -> Int {
    let xs = [1, 2]
    return xs.count
}
```
