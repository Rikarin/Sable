# S0001: a character the language does not use

The source contains a character that cannot begin any token: not a letter,
digit, operator, bracket or quote that Sable knows. Characters such as `¤`,
`§` or a typographic quote usually come from text pasted from a document or
a web page. Outside a string or a comment, Sable uses only ASCII
punctuation.

The lexer reports the character and passes it on as a bad token, so the
parser then reports what it expected in its place, usually an expression
(S1002) or a declaration (S1008). Fix this error first: the ones after it
on the same line go away with it.
