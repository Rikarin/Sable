# S3472: unsafe code in a build that denies it

The program is built with `sable build --deny-unsafe`, and its own code has
an `unsafe { }` block or declares an `unsafe fn` (SYNTAX.md §23). Such a build
promises that the program's own code keeps every promise the compiler checks:
each `unsafe` block and `unsafe fn` is one it cannot.

What is counted is the program's own source: the standard library and the
package's dependencies may use `unsafe` behind safe APIs, as
`String.fromUtf8` does.

Either remove the unsafe code — calling the safe API beside the unsafe one,
as `String.fromUtf8` beside `String.fromUtf8Unchecked` — or build without
`--deny-unsafe`.
