# S3011: unwrapping something that is not optional

An operation that only makes sense on an optional was used on a value that
is not one, such as `!` on a plain `Int`: there is nothing to unwrap. The
reverse mistake, reaching through an optional with `.` instead of `?.`, is
reported with the same code.

## Example

```sable
module Example

fn value(_ n: Int) -> Int {
    return n!
}
```

## Fix

```sable
module Example

fn value(_ n: Int) -> Int {
    return n
}
```
