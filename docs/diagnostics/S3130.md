# S3130: `~` opts out of nothing here

Every generic parameter is implicitly `Copyable`, and `~Copyable` lifts that
one implicit constraint so a `@noncopy` type may stand for the parameter. It
is written only in a parameter's constraint, `T: ~Copyable`, or in a `where`
clause, `where T: ~Copyable`, and only `Copyable` can be lifted: there is no
other implicit constraint to opt out of.

## Example

```sable
module Example

struct Box<T> {
    var value: ~Copyable
}
```

## Fix

```sable
module Example

struct Box<T: ~Copyable> {
    var value: T
}
```
