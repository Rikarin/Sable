# S3420: a type where a number goes, or a number where a type goes

A generic parameter constrained to an integer type, such as the `N` of
`struct Buf<T, N: Int>`, is a value parameter: it stands for a number, and
is given one, `Buf<Int, 4>`. Every other generic parameter stands for a type
and is given one. A number given to a type parameter, a type given to a
value parameter, or a number too large to be one, is this error. So is a
constant given by name, `Buf<Int, size>`, whose value is not known while
types are read: one computed by a call rather than integer arithmetic over
literals and other constants.

## Example

```sable
module Example

struct Buf<T, N: Int> {
    var items: T[N]
}

fn main() {
    let b: Buf<Int, String>? = none
    print(b == none)
}
```

## Fix

```sable
module Example

struct Buf<T, N: Int> {
    var items: T[N]
}

fn main() {
    let b: Buf<Int, 4>? = none
    print(b == none)
}
```
