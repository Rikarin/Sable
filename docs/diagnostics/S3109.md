# S3109: a test the harness cannot reach

The harness calls each test from outside the type that declares it, with no type arguments. So a `@test` or `@bench` method cannot be `private`, and cannot belong to a generic type; and it needs a body.

## Example

```sable
module Example

import Sable.Testing

struct Parser {
    @test
    private static fn parsesNothing() {
        assert(true)
    }
}
```

## Fix

Make the method `internal` (the default), or move it out of a generic type.

```sable
module Example

import Sable.Testing

struct Parser {
    @test
    static fn parsesNothing() {
        assert(true)
    }
}
```
