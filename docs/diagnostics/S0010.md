# S0010: a Unicode escape that is not a valid scalar value

The number in a `\u{...}` escape must be a Unicode scalar value: at most
`10FFFF`, and not a surrogate in `D800` to `DFFF`. Surrogates exist only in
UTF-16 encodings; a character outside the Basic Multilingual Plane is written
with its own code point, not as a surrogate pair.

## Example

```sable
module Example

fn smile() -> String {
    return "\u{D83D}\u{DE00}"
}
```

## Fix

```sable
module Example

fn smile() -> String {
    return "\u{1F600}"
}
```
