# S1004: an identifier was expected

The parser needed a name here, for instance after `let`, `var`, `fn`,
`struct` or a `.`, and found something else. A keyword cannot be used as a
name unless it is escaped in backquotes, as in `` `type` ``.

## Example

```sable
module Example

fn one() -> Int {
    let = 1
    return 1
}
```

## Fix

```sable
module Example

fn one() -> Int {
    let value = 1
    return value
}
```
