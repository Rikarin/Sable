# S3100: a test that takes parameters

A `@test` function is called by the harness `sable test` builds, which has nothing to pass it: a test takes no parameters. To run the same check on several inputs, loop over them inside the test, or write one test per input.

## Example

```sable
module Example

import Sable.Testing

@test
fn addsUp(_ n: Int) {
    assertEqual(n + n, n * 2)
}
```

## Fix

Take the inputs from inside the test.

```sable
module Example

import Sable.Testing

@test
fn addsUp() {
    for n in [0, 1, 7, 100] {
        assertEqual(n + n, n * 2)
    }
}
```
