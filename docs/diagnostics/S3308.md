# S3308: a call's result left unused

The `unused_result` lint, a warning by default. A call that gives a value
is written as a statement of its own, so the value is dropped. That is
often a mistake — `text.trimmed()` changes nothing by itself — so it is
reported, unless the function is marked `@discardable`, which says that
calling it for what it does is normal. Write `let _ = f()` to drop a value on
purpose.

## Example

```sable
module Example

fn twice(_ n: Int) -> Int {
    return n * 2
}

fn run() {
    twice(4)
}
```

## Fix

```sable
module Example

@discardable
fn twice(_ n: Int) -> Int {
    return n * 2
}

fn run() {
    twice(4)
}
```
