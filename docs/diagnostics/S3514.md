# S3514: a `@main` the program cannot start at

`@main` marks the function a program starts at. The process calls it with
nothing and exits with what it returns, so it is:

- a function of the module, not a method or a function inside another;
- not generic, and without parameters — the program's arguments are
  `Environment.arguments()`;
- one that returns nothing, or an `Int`, the exit status;
- the module's only `@main`.

## Example

```sable
module Example

@main
fn start(_ arguments: String[>..]) -> Int {
    return arguments.count
}
```

## Fix

```sable
module Example

import Sable.IO

@main
fn start() -> Int {
    return Environment.arguments().count
}
```
