# S1014: `@escaping` is written on the parameter's type

What a closure parameter may do with the closure it is given is part of its
type, as Swift has it: `f: @escaping () -> Int` may keep `f` past the call,
and `(@escaping () -> Int) -> ()` is a function type of its own. So are
`@autoclosure` and `@Sendable`. They are written after the colon, before the
type, and nowhere else.

`@escaping f: () -> Int` is not Sable. It is read as the parameter it meant,
and the fix moves the attribute onto the type.

## Example

```sable
module Example

fn keep(@escaping _ f: () -> Int) -> () -> Int {
    return f
}
```

## Fix

```sable
module Example

fn keep(_ f: @escaping () -> Int) -> () -> Int {
    return f
}
```
