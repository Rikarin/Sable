# S3007: no overload takes these arguments

A call's arguments do not fit the function: there are too many or too few,
a label is wrong, an argument has the wrong type, or a generic argument does
not satisfy a constraint. When the name is overloaded, the message lists up
to three candidates and why each one was turned down.

## Example

```sable
module Example

fn double(_ n: Int) -> Int { return n * 2 }

fn four() -> Int {
    return double(2, 2)
}
```

## Fix

```sable
module Example

fn double(_ n: Int) -> Int { return n * 2 }

fn four() -> Int {
    return double(2)
}
```
