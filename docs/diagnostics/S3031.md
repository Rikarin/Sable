# S3031: extending a type that has no name

Only a named type can be extended. Tuples, function types and other
structural types have no declaration to attach members to.

## Example

```sable
module Example

extension (Int, Int) {
    fn sum() -> Int { return 0 }
}
```

## Fix

Declare a named type for the shape, and extend that.

```sable
module Example

struct Pair { var a: Int, var b: Int }

extension Pair {
    fn sum() -> Int { return a + b }
}
```
