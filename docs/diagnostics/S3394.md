# S3394: arithmetic that always traps

The `constant_arithmetic` lint, a warning by default. Integer arithmetic in
a function divides by a zero written out (`n / 0`, `n % (2 - 2)`), or works
only on numbers written out and overflows its type
(`9223372036854775807 + 1`). Either one traps every time it runs.

The same arithmetic in a `const`'s initialiser is the compiler's error
S3201, since the compiler works it out; in a function body it is left to run,
so it is this lint that says so.

## Example

```sable
module Example

fn average(_ total: Int) -> Int {
    return total / 0
}
```

## Fix

```sable
module Example

fn average(_ total: Int, _ count: Int) -> Int {
    return count == 0 ? 0 : total / count
}
```
