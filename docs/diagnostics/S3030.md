# S3030: an extension with an initialiser

A class's extension may not add an initialiser but a `convenience` one, which
delegates with `self.init(…)`: any other would be a designated one, and those
belong with the class's declaration, which knows every stored field that must
be set and the superclass's initialiser to call. Nor may an
extension of a protocol, or of every fixed-size or inline array, or of the
slice. A struct's, an enum's, a union's or a built-in type's extension may
add one that gives self its value, and an extension of every growable array
of a kind one that starts from `[]`.

## Example

```sable
module Example

class Point {
    var x: Int = 0
    var y: Int = 0
}

extension Point {
    init(_ n: Int) {
        self.x = n
        self.y = n
    }
}
```

## Fix

```sable
module Example

class Point {
    var x: Int = 0
    var y: Int = 0
}

extension Point {
    static fn square(_ n: Int) -> Point {
        let point = Point()
        point.x = n
        point.y = n
        return point
    }
}
```
