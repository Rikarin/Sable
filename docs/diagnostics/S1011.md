# S1011: an opening brace on a line of its own

The `{` that opens a body must be on the same line as the header it belongs
to. Sable ends a statement at the end of a line, so a `{` that starts a line
would read as a block, or a trailing closure, of its own. The compiler still
takes it as the body, so the rest of the file parses as intended.

## Example

```sable
module Example

fn one() -> Int
{
    return 1
}
```

## Fix

```sable
module Example

fn one() -> Int {
    return 1
}
```
