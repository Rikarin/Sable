# S3013: iterating something that cannot be iterated

A `for ... in` loop was given a value that is not a sequence. Arrays,
dictionaries, ranges of integers or characters, strings and types that
conform to `Sequence` can be iterated; a plain struct cannot, a range over
any other type does not enumerate, and a range open at the start (`..<b`)
has no first value. `for await` needs an `AsyncSequence`.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn total(_ p: Point) -> Int {
    var sum = 0
    for n in p { sum += n }
    return sum
}
```

## Fix

```sable
module Example

struct Point { var x: Int, var y: Int }

fn total(_ p: Point) -> Int {
    var sum = 0
    let parts = [p.x, p.y]
    for n in parts { sum += n }
    return sum
}
```
