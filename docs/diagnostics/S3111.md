# S3111: a property kept in `field` with no initial value

A property whose accessors say `field` keeps its value there: storage of the
type's own, which only the property's accessors can name. Nothing else can
set that storage first — a record literal or memberwise initialiser names
the property, not its storage — so it takes its starting value from the
property's initialiser.

## Example

```sable
module Example

struct Account {
    var owner: String {
        get => field
        set => field = newValue.trimmed()
    }
}
```

## Fix

Give the property the value its storage starts with.

```sable
module Example

struct Account {
    var owner: String = "" {
        get => field
        set => field = newValue.trimmed()
    }
}
```
