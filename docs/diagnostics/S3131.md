# S3131: a move-only type argument to a parameter that copies

A generic parameter is implicitly `Copyable`: the generic code may copy a
value of it. A `@noncopy` type can never be copied, so it stands for a
parameter only where the declaration says it does not need to, with
`T: ~Copyable`. The same goes for a parameter that is itself `~Copyable`,
since what it stands for may be move-only.

## Example

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

struct Box<T> {
    var value: T
}

fn make() -> Box<Handle> {
    return Box<Handle> { value: Handle { id: 1 } }
}
```

## Fix

```sable
module Example

@noncopy struct Handle {
    var id: Int
}

struct Box<T: ~Copyable> {
    var value: T
}

fn make() -> Box<Handle> {
    return Box<Handle> { value: Handle { id: 1 } }
}
```
