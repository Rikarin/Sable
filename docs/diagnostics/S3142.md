# S3142: an enum case's value that is not one

An enum case names an integer. The value it writes is a constant: an integer
literal, an earlier case of the same enum, or those combined with
`| & ^ + - * << >> ~`; a case that writes none is the one after the previous
case. Outside a `@flags` enum, whose values are sets of its cases, each case
is a different integer, so that `n as Status` has one answer.

## Example

```sable
module Example

enum Status: U8 {
    Pending = 0
    Active = 1
    Closed = 1
}
```

## Fix

Give each case its own value.

```sable
module Example

enum Status: U8 {
    Pending = 0
    Active = 1
    Closed = 9
}
```
