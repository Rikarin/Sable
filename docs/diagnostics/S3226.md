# S3226: a C function pointer of something that captures

Sable.Interop's `cFunction` makes a C function pointer, which is an address
and nothing else: there is nowhere for what a closure captured to go. So it is
given a function by its name, or a closure written there that captures
nothing. A closure that captures goes to C as a pointer and a context, which
C hands back as it calls: `withCallback` for the length of a call, `CCallback`
for longer.

## Example

```sable
module Example

import Sable.Interop

fn scaled(by factor: CInt) -> CFunction<(CInt) -> CInt> {
    return cFunction { (n: CInt) -> CInt in n * factor }
}
```

## Fix

```sable
module Example

import Sable.Interop

fn scaled(by factor: CInt) -> CCallback<(CInt, RawPtr<Opaque>) -> CInt> {
    return CCallback { (n: CInt, context: RawPtr<Opaque>) -> CInt in n * factor }
}
```
