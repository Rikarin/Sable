# S3482: `return` with a value in a generator

A generator gives its elements with `yield`; its result is the sequence those
make, which the call returns before the body runs (SYNTAX.md §5,
"Generators"). `return` in its body only ends it, so it takes no value.

## Example

```sable
module Example

fn countdown(from n: Int) -> some Sequence<Int> {
    var i = n
    while i > 0 {
        yield i
        i -= 1
    }
    return 0
}
```

## Fix

Yield the value, then end:

```sable
module Example

fn countdown(from n: Int) -> some Sequence<Int> {
    var i = n
    while i > 0 {
        yield i
        i -= 1
    }
    yield 0
    return
}
```
