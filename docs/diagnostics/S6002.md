# S6002: the wrong number of values for a union case

A union case declares how many values it carries, and every pattern or
construction of that case must give exactly that many: `.Rect(let w, let h)`
for a case declared `Rect(width: F64, height: F64)`. A case with values
cannot be constructed without them either.

## Example

```sable
module Example

union Shape { Circle(radius: F64), Rect(width: F64, height: F64) }

fn width(_ s: Shape) -> F64 {
    return match s {
        case .Circle(let r) => r * 2.0
        case .Rect(let w) => w
    }
}
```

## Fix

Bind every value, using `_` for the ones you do not need.

```sable
module Example

union Shape { Circle(radius: F64), Rect(width: F64, height: F64) }

fn width(_ s: Shape) -> F64 {
    return match s {
        case .Circle(let r) => r * 2.0
        case .Rect(let w, _) => w
    }
}
```
