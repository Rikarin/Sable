# S3096: a declaration not available on this platform

`@available(macos, linux)` says which platforms a declaration exists on.
Using it in a build for any other platform is an error, so that code meant
for one system does not reach another by accident. The platforms are those
`#if os(...)` tests: `macos`, `linux`, `windows` and `wasi`.

## Example

```sable
module Example

@available(windows)
fn registryKey() -> String {
    return "HKEY_CURRENT_USER"
}

fn settings() -> String {
    return registryKey()
}
```

## Fix

```sable
module Example

@available(windows)
fn registryKey() -> String {
    return "HKEY_CURRENT_USER"
}

@available(windows)
fn settings() -> String {
    return registryKey()
}
```
