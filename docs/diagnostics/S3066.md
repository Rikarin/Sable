# S3066: `~Copyable` where a type is wanted

`~Copyable` is not a type. It lifts the `Copyable` constraint every generic
parameter has unless it says otherwise, and is written only as that
parameter's constraint: `T: ~Copyable`, or `where T: ~Copyable`. A parameter
that should take a move-only value is written with the type itself, or with
a generic parameter that allows one.

## Example

```sable
module Example

@noncopy struct Token { var id: Int }

fn show(_ x: consuming ~Copyable) {}

@main
fn main() {
    show(Token(id: 1))
}
```

## Fix

```sable
module Example

@noncopy struct Token { var id: Int }

fn show<T: ~Copyable>(_ x: consuming T) {}

@main
fn main() {
    show(Token(id: 1))
}
```
