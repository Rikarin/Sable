# S3009: an operator not defined for these types

An operator was applied to operands whose types do not define it. `+` on two
structs needs an operator declared for that struct, and arithmetic needs
both sides to have compatible numeric types.

## Example

```sable
module Example

struct Point { var x: Int, var y: Int }

fn sum(_ p: Point, _ q: Point) -> Point {
    return p + q
}
```

## Fix

Declare the operator, or combine the fields yourself.

```sable
module Example

struct Point { var x: Int, var y: Int }

fn sum(_ p: Point, _ q: Point) -> Point {
    return Point { x: p.x + q.x, y: p.y + q.y }
}
```
