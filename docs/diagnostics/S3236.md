# S3236: a task's closure captures what is not Sendable

`Task.spawn`, `Task.detached`, a task group's `spawn`, `Task.blocking` and
`async let` run a closure alongside the code that wrote it — as a task of
its own, maybe on another core — so what the closure captures is held by
both at once. It crosses a boundary as an actor's arguments do, and must be
`Sendable`: a value made of Sendable parts, an actor, or an `@immutable` or
`@MainActor` class. A `var` would be one variable both change, each racing
the other: copy it into a `let`, or capture its value in a capture list.

The closure must be written where the task is made, so that its captures
can be seen. A named function, which captures nothing, will do, as will a
parameter declared `@Sendable` — whose closure was checked where it was
written. A parameter that runs its closure as a task is declared so:

```sable
fn later(_ body: @Sendable async () -> Int) -> Task<Int> {
    return Task.spawn(body)
}
```

A thread's closure (`Thread.spawn`, docs/06 §6.7), and a parallel loop's, are
the same. A thread of a `Thread.scope` ends before the scope does, so it may
use a `var` of the function that calls `Thread.scope`, where it is — if the
`var` is its alone until the scope ends:

- the thread is spawned on that scope, in the scope's own closure, and not in
  a loop;
- nothing else in the scope mentions the `var`, the scope's code or another
  thread's;
- no other closure of the function does, which the scope might call.

In an `unsafe` block the programmer vouches for what is shared — that
something else, a latch or the order of the program, keeps the tasks from
touching it at once — and the capture is not checked.

## Example

```sable
module Example

class Tally {
    var count: Int = 0
}

@main
async fn main() {
    let tally = Tally()
    let task = Task.spawn { tally.count += 1 }
    await task.value
    print(tally.count)
}
```

## Fix

Keep the state in an actor, which runs one call at a time.

```sable
module Example

actor Tally {
    var count = 0

    fn add() {
        count += 1
    }
}

@main
async fn main() {
    let tally = Tally()
    let task = Task.spawn { await tally.add() }
    await task.value
    print(await tally.count)
}
```
