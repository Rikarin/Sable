# S3112: a member with no body

A function, accessor or subscript written without a body has nothing to run.
Only some declarations go without one, because something else supplies it:

- a protocol's requirements, which each conforming type implements;
- an `abstract` method of an `abstract` class, which each subclass overrides;
- a `@builtin`, `@intrinsic` or `@extern` declaration, whose body is the
  compiler's or a foreign library's;
- `get` or `set` written alone in a property kept in `field`, which are the
  plain ones.

## Example

```sable
module Example

struct Circle {
    var radius: F64
    var area: F64 { get }
    fn scaled(by factor: F64) -> Circle
}
```

## Fix

Give each one a body, or declare it in a protocol the type conforms to.

```sable
module Example

struct Circle {
    var radius: F64
    var area: F64 => radius * radius * 3.14159
    fn scaled(by factor: F64) -> Circle {
        return Circle { radius: radius * factor }
    }
}
```
