# S1009: nesting too deep to parse

Brackets, blocks or other constructs are nested more than 256 levels deep.
The parser stops reading that construct, skips to the bracket that closes
the group it sits in, and goes on from there; the error is reported once.

Real code does not come near this limit, which exists so that a generated or
corrupted file cannot exhaust the compiler's stack. Hand-written code that
meets it should be split into smaller functions or intermediate bindings.
