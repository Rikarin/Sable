# S3021: a leading-dot name with no type to look in

`.North` is short for a member of the type the context expects: `Direction`
if the value is assigned to a `Direction`, passed to a `Direction` parameter,
and so on. With no expected type, the compiler cannot tell which type's
member is meant.

## Example

```sable
module Example

enum Direction { North, South }

fn heading() -> Direction {
    let d = .North
    return d
}
```

## Fix

Annotate the binding, or name the type: `Direction.North`.

```sable
module Example

enum Direction { North, South }

fn heading() -> Direction {
    let d: Direction = .North
    return d
}
```
