# S3010: assigning to something that cannot be assigned

The left side of an assignment is not a mutable place. A `let` binding never
changes after its initialiser, and a property whose setter is less visible
than its getter can be read but not written from outside.

## Example

```sable
module Example

fn next() -> Int {
    let count = 1
    count = 2
    return count
}
```

## Fix

Declare the binding with `var` if it is meant to change.

```sable
module Example

fn next() -> Int {
    var count = 1
    count = 2
    return count
}
```
